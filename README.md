Pilih kualitas **360p sampai 1080p**, kecepatan **0,5× sampai 2×**, dan mode pas atau isi layar. Kualitas bawaan bisa dibedakan untuk Wi-Fi dan data seluler.

Otomatis lewat data AniSkip, atau pakai tombol **+85 dtk**. Episode berikutnya diputar sendiri, video bisa jalan di **Picture-in-Picture**, dan suara tetap terdengar saat layar mati.

Per hari lengkap dengan jam rilis, plus notifikasi episode baru untuk anime favoritmu.

## 📖 Baca

**Satu judul, tiga sumber**

Indonesia, Inggris, atau Raw. Hanya bahasa yang benar-benar tersedia untuk judul itu yang ditampilkan.

Bisa difilter langsung di tab Manga. Judul lama yang sudah tamat ikut tersedia dari arsip Komiku.

Dengan pemilih chapter, tombol Prev dan Next, lanjut dari halaman terakhir, dan mode hemat data.

## 💾 Simpan

<table>
  <tr>
    <td valign="top">

**Unduh episode & chapter**
Tonton atau baca tanpa internet: satu episode, semua episode, satu chapter, atau rentang 1–100 sekaligus.

**Simpan ke mana?**
Setiap kali mengunduh, pilih di dalam aplikasi atau ke folder pilihanmu. Di folder pilihan, tiap judul punya folder sendiri dengan nama file berurutan, misalnya `Judul - Ep 01 (720p).mkv`.

**Koleksi**
Menyatukan riwayat, favorit, manga, dan unduhan. Semuanya bisa dibackup ke folder pilihanmu dan dipulihkan di HP lain.

**Tahan offline**
Layar yang pernah dibuka langsung tampil dari data terakhir, lalu diperbarui diam-diam begitu internet kembali.

## 📲 Pasang

1. Buka halaman [**rilis terbaru**](https://github.com/fuwanime/fuwastream/releases/latest).
2. Unduh file **APK** di bagian **Assets**.
3. Buka APK di HP dan izinkan instalasi dari sumber itu bila diminta.
4. Buka FuwaStream dan selamat menonton! 🎉

> [!IMPORTANT]
> Unduh APK **hanya** dari halaman rilis resmi repository ini. Butuh **Android 7.0 (API 24)** atau lebih baru.

## 🧰 Teknologi

Dibangun dengan **Kotlin** dan **Jetpack Compose** (Material 3).

| Bagian | Teknologi |
| :--- | :--- |
| Pemutar | Media3 ExoPlayer |
| Data di HP | Room, DataStore |
| Tugas latar | WorkManager (unduhan & backup) |
| Jaringan | Retrofit, OkHttp, Moshi |
| Gambar | Coil 3 |
| CI/CD | GitHub Actions |

### Sumber data

| Sumber | Dipakai untuk |
| :--- | :--- |
| **Animein** | Katalog, jadwal, dan sumber pemutaran anime |
| **AniList**, **AniSkip** | Info tambahan anime dan penanda opening |
| **MangaDex** | Manga multi-bahasa (Indonesia, Inggris, Raw) |
| **Shinigami**, **Komiku** | Manga berbahasa Indonesia |

## 🛠️ Build dari Source

<details>
<summary><b>Langkah build</b></summary>

<br>

Butuh **JDK 17+**, **Android SDK 36**, dan Gradle yang kompatibel.

```bash
git clone https://github.com/fuwanime/fuwastream.git
cd fuwastream
gradle testDebugUnitTest assembleDebug
```

APK debug ada di `app/build/outputs/apk/debug/app-debug.apk`.

**Alur GitHub Actions**

| Pemicu | Hasil |
| :--- | :--- |
| Push ke `main` / PR | Unit test dan kompilasi APK/AAB sebagai artefak verifikasi CI |
| Rilis SemVer manual (`workflow_dispatch`) | Bump versi SemVer (Major/Minor/Patch) dan publikasi di [Releases](https://github.com/fuwanime/fuwastream/releases) |
| Tag `v*.*.*` | Build rilis dan publikasi otomatis sesuai tag SemVer |
| Manual · `smoke` / `qa` | Uji di emulator Android dengan tangkapan layar dan rekaman |
| Manual · `profile` | Membuat ulang *baseline profile* untuk optimasi *cold start* |

</details>

<details>
<summary><b>Struktur proyek</b></summary>

<br>

```text
com.fuwanime
├── data/
│   ├── remote/       # API anime, DTO, cache dan status jaringan
│   ├── manga/        # MangaDex, Shinigami, Komiku, gabung sumber, unduhan manga
│   ├── meta/         # AniList dan AniSkip
│   ├── backup/       # Backup dan pulihkan data
│   └── local/        # Room dan DataStore
├── playback/         # Layanan pemutaran dan audio latar
├── ui/               # Paket per layar (Screen + ViewModel)
│   ├── components/   # Komponen UI yang dipakai ulang
│   ├── manga/        # Tab, detail, dan reader manga
│   ├── navigation/   # Navigasi aplikasi
│   └── theme/        # Tema, warna, tipografi
└── util/             # Helper dan utilitas
```

</details>

## ⚠️ Catatan Konten

FuwaStream adalah aplikasi klien dan **tidak meng-host video maupun gambar manga**. Informasi dan sumber pemutaran datang dari layanan pihak ketiga, jadi ketersediaannya bergantung pada layanan tersebut. Pengguna bertanggung jawab mematuhi hukum, hak cipta, dan ketentuan layanan di wilayahnya. Nama, logo, dan aset pihak ketiga tetap milik pemegang haknya; gambar manga berasal dari MangaDex, Shinigami, dan Komiku beserta grup scanlation masing-masing.

## Cara kerja

### Satu manga dari tiga sumber

```mermaid
flowchart LR
    O["Judul yang dibuka"] --> F{"Cari judul yang sama"}
    F --> MD["MangaDex"]
    F --> SH["Shinigami"]
    F --> KM["Komiku"]
    MD --> G["Gabung per nomor chapter"]
    SH --> G
    KM --> G
    G --> L{"Bahasa dipilih: ID / EN / Raw"}
    L --> P["Per chapter: yang bisa dibaca dulu, lalu Shinigami, Komiku, MangaDex"]
    P --> D["Satu daftar chapter"]
```

### Cepat dan tahan offline

```mermaid
flowchart LR
    A["Layar"] --> R["Repository"]
    R -->|"buka instan"| C[("Cache 50 MB")]
    R -->|"perbarui diam-diam"| N["API"]
    N -. "simpan" .-> C
    N -- "gagal atau offline" --> C
```

- **Buka instan**: Beranda tampil dari data terakhir tanpa layar loading, lalu diperbarui di belakang layar.
- **Tetap jalan tanpa internet**: layar yang pernah dibuka tetap bisa dilihat, begitu juga episode dan chapter yang sudah diunduh.
- **Jaringan yang memblokir**: alamat sumber manga dicari lewat DNS-over-HTTPS bila DNS operator mengarahkannya ke halaman blokir.

## Build dari source

<details>
<summary><b>Persyaratan dan langkah build</b></summary>

<br>

**Persyaratan:** JDK 17+, Android SDK 36, dan Gradle yang kompatibel.

```bash
git clone https://github.com/fuwanime/fuwastream.git
cd fuwastream
gradle testDebugUnitTest assembleDebug
```

APK debug ada di `app/build/outputs/apk/debug/app-debug.apk`.

</details>

<details>
<summary><b>Build otomatis (GitHub Actions)</b></summary>

<br>

| Pemicu | Hasil |
|---|---|
| Push ke `main` | Test dan APK release, terbit di [Releases](https://github.com/fuwanime/fuwastream/releases) sebagai `build-N` |
| Tag `v*` | Rilis dengan nama versi tersebut |
| Manual · `smoke` / `qa` | Uji di emulator dengan screenshot dan rekaman layar |
| Manual · `profile` | Membuat ulang *baseline profile* |

Gambar anime di README ini dibuat dari screenshot QA dengan `scripts/readme_images.sh`.

</details>

<details>
<summary><b>Struktur proyek</b></summary>

<br>

```text
com.fuwanime
├── data/
│   ├── remote/       # API anime, DTO, cache dan status jaringan
│   ├── manga/        # MangaDex, Shinigami, Komiku, gabung sumber, unduhan manga
│   ├── meta/         # AniList dan AniSkip
│   ├── backup/       # Backup dan pulihkan data
│   └── local/        # Room dan DataStore
├── playback/         # Layanan pemutaran dan audio latar
├── ui/               # Paket per layar (Screen + ViewModel)
│   ├── components/   # Komponen UI yang dipakai ulang
│   ├── manga/        # Tab, detail, dan reader manga
│   ├── navigation/   # Navigasi aplikasi
│   └── theme/        # Tema, warna, tipografi
└── util/             # Helper dan utilitas
```

</details>

## Catatan konten

> [!NOTE]
> FuwaStream adalah aplikasi klien dan **tidak meng-host file video maupun gambar manga**. Informasi dan sumber pemutaran berasal dari API atau layanan pihak ketiga, sehingga ketersediaan konten bergantung pada layanan tersebut. Pengguna bertanggung jawab mematuhi hukum, hak cipta, dan ketentuan layanan yang berlaku di wilayahnya. Nama, logo, dan aset pihak ketiga tetap milik pemegang haknya. Data dan gambar manga berasal dari MangaDex, Shinigami, dan Komiku beserta grup scanlation masing-masing. FuwaStream tidak menampilkan iklan.

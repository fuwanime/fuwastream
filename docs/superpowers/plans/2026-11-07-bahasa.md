# Bahasa (ms, en, zh-CN) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Semua teks app berasal dari string resource dalam empat bahasa (Indonesia default, Melayu, English, 中文简体), dengan pilihan bahasa di Pengaturan dan di Setelan sistem Android 13+.

**Architecture:** Teks dipindah ke file resource per area (`values/strings_<area>.xml` + `values-ms`, `values-en`, `values-zh-rCN`), sehingga tiap area bisa dikerjakan terpisah tanpa konflik file. Fungsi logika murni yang menghasilkan teks menerima `Resources` sebagai parameter pertama dan tetap dites (Robolectric, hanya `testImplementation`). Pilihan bahasa: `LocaleManager` di API 33+, `attachBaseContext` + SharedPreferences di API 24–32.

**Tech Stack:** Android resources (`<string>`, `<plurals>`), Compose `stringResource`/`pluralStringResource`, `LocaleManager`, Robolectric (test saja), JUnit4.

**Spec:** `docs/superpowers/specs/2026-11-07-statistik-backup-bahasa-design.md` — Sub-proyek 3.

## Global Constraints

- Default (`values/`) = Bahasa Indonesia, teks persis seperti sekarang (perilaku untuk user Indonesia tidak berubah).
- Bahasa tambahan: `values-ms`, `values-en`, `values-zh-rCN`. Kunci identik di keempatnya, kecuali `legal_*` yang hanya ada di `values` dan `values-en`.
- Tidak diterjemahkan: "fuwastream", judul/genre/sinopsis dari API, nama kualitas ("720p"), "Picture-in-Picture" boleh tetap.
- Placeholder bernomor (`%1$s`, `%1$d`); jumlah memakai `<plurals>` (id/ms/zh: `other` saja cukup, en: `one` + `other`).
- Tanpa dependensi app baru. Robolectric hanya `testImplementation`.
- Nama kunci: `<area>_<makna>` dalam snake_case Inggris, mis. `library_title`, `player_lock_screen`, `common_cancel`.
- Teks dari ViewModel diubah menjadi `@StringRes` (+ argumen) dan di-resolve di UI.
- Verifikasi: `ci-test.sh` (unit test + `assembleRelease` dengan lint `MissingTranslation` fatal bawaan rilis). Tanpa QA emulator. Merge ke fork setelah CI hijau.
- Commit tanpa baris co-author Claude.

## Review Focus

- **Teks tertinggal hard-coded** setelah pemindahan (user English melihat campuran). → Task 7 grep sisa literal huruf di `Text(`, `contentDescription`, `showSnackbar`, `label =` dan mencatat pengecualian yang disengaja.
- **Placeholder tidak cocok antar bahasa** (`%1$d` di id, `%d` di zh) → crash `IllegalFormatException` saat runtime hanya di satu bahasa. → test `placeholdersMatchAcrossLocales` di Task 1.
- **Notifikasi/widget/worker memakai bahasa sistem, bukan pilihan app di API < 33.** → Task 6 memakai `localizedContext(context)`; test `resolveAppLocale`.
- **Ganti bahasa di API < 33 tidak berlaku sampai app ditutup.** → Task 1: `recreate()` setelah simpan.
- **Teks hukum**: ms/zh harus menampilkan EN, bukan ID. → test `legalLocale` di Task 1.

**Files:**

- Modify: `gradle/libs.versions.toml`, `app/build.gradle.kts` (Robolectric `4.16`, `testOptions.unitTests.isIncludeAndroidResources = true`)
- Test: `app/src/test/java/com/fuwanime/AppLocaleTest.kt`, `app/src/test/java/com/fuwanime/StringsCompletenessTest.kt`

**Interfaces:**
- Produces (di `AppLocale.kt`):
  - `val SUPPORTED_LANGUAGES = listOf("id", "ms", "en", "zh")`
  - `fun resolveAppLocale(tag: String?, system: Locale): Locale` — tag tidak kosong → `Locale.forLanguageTag(tag)`; kosong/null → bahasa sistem bila `system.language` ∈ SUPPORTED (zh apa pun → `Locale.SIMPLIFIED_CHINESE`), selain itu `Locale("id")`.
  - `fun legalLocale(appLocale: Locale): Locale` — `id` → `Locale("id")`, selain itu `Locale.ENGLISH`.
  - `fun savedLanguageTag(context: Context): String?` / `fun setAppLanguage(activity: Activity, tag: String?)` — API 33+: `LocaleManager.applicationLocales = LocaleList.forLanguageTags(tag ?: "")`; API < 33: simpan di `SharedPreferences("locale").putString("tag", tag)` lalu `activity.recreate()`.
  - `fun localizedContext(context: Context): Context` — API 33+: `context` apa adanya; < 33: `createConfigurationContext` dengan `resolveAppLocale(savedLanguageTag, Locale.getDefault())`.
  - `fun currentLanguageTag(context: Context): String?` — API 33+ dari `LocaleManager.applicationLocales.toLanguageTags()`, < 33 dari prefs; kosong → null (= Sistem).
- `MainActivity.attachBaseContext(base)` → `super.attachBaseContext(localizedContext(base))`.
- Pengaturan, grup "Tampilan": `ChoiceRow` "Bahasa" dengan pilihan `null` "Ikuti sistem", `"id"` "Bahasa Indonesia", `"ms"` "Bahasa Melayu", `"en"` "English", `"zh-CN"` "中文（简体）" (nama bahasa ditulis dalam bahasanya sendiri, bukan resource terjemahan); pilih → `setAppLanguage`.

- [ ] **Step 1: Test yang gagal**
  - `AppLocaleTest`: `resolveAppLocale("ms", Locale.US).language == "ms"`; `resolveAppLocale(null, Locale("ms","MY")).language == "ms"`; `resolveAppLocale("", Locale.FRANCE).language == "id"`; `resolveAppLocale(null, Locale.TRADITIONAL_CHINESE) == Locale.SIMPLIFIED_CHINESE`; `legalLocale(Locale("id")).language == "id"`; `legalLocale(Locale("ms")) == Locale.ENGLISH`; `legalLocale(Locale.SIMPLIFIED_CHINESE) == Locale.ENGLISH`.
  - `StringsCompletenessTest` (JVM murni, membaca XML dari `src/main/res` relatif ke `System.getProperty("user.dir")` = modul `app`):
    - `everyKeyTranslated`: kumpulan nama `<string>`/`<plurals>` dari semua `values/strings*.xml` (tanpa `translatable="false"`) sama dengan kumpulan di `values-ms`, `values-en`, `values-zh-rCN`, kecuali awalan `legal_` yang wajib di `values-en` saja dan tidak boleh ada di ms/zh.
    - `placeholdersMatchAcrossLocales`: untuk tiap kunci, multiset `%\d+\$[sd]` sama di semua bahasa (untuk plurals: per item, dibandingkan dengan item `other`).
    - `noUnnumberedPlaceholders`: tidak ada `%s`/`%d` tanpa nomor.
- [ ] **Step 2:** RED (ci-test.sh: kompilasi gagal `resolveAppLocale`; completeness lulus trivial — catat di ledger).
- [ ] **Step 3:** Implementasi sesuai Interfaces; `locales_config.xml` berisi `id`, `ms`, `en`, `zh-CN`.
- [ ] **Step 4:** GREEN.
- [ ] **Step 5: Commit** `feat(bahasa): pilihan bahasa app dan test kelengkapan terjemahan`

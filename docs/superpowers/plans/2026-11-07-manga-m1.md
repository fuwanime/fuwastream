# Manga M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pengguna bisa menjelajah, mencari, membuka detail, dan membaca manga (chapter `id`/`en`) dari MangaDex di app, dengan riwayat lanjut baca, favorit, dan mode hemat data.

**Architecture:** Paket baru `data/manga/` (API Retrofit, model + pemetaan murni, repository, rate limiter) dan `ui/manga/` (beranda manga, jelajah manga, detail, reader). Tabel Room baru untuk favorit & riwayat (v4→v5). Saklar Anime | Manga di Beranda dan Jelajah memilih konten; Koleksi dan Pengaturan mendapat bagian Manga.

**Tech Stack:** Kotlin 2.2.10, Compose Material3, Retrofit + Moshi codegen, OkHttp (MockWebServer di test), Coil, Room, DataStore, Robolectric (test), JUnit4.

**Spec:** `docs/superpowers/specs/2026-11-07-manga-design.md`

## Global Constraints

- Sumber: MangaDex API v5 `https://api.mangadex.org`, tanpa key. Gambar dari `uploads.mangadex.org` (cover) dan `{baseUrl}` dari `/at-home/server/{chapterId}`.
- Header `User-Agent: FuwaStream/<versionName> (github.com/SakamotoMrX/fuwanime)` pada permintaan ke `api.mangadex.org`; tidak ada header auth ke server gambar.
- `contentRating[]=safe&contentRating[]=suggestive` saja; katalog difilter `availableTranslatedLanguage[]=id&availableTranslatedLanguage[]=en`.
- Tanpa dependensi app baru. Teks baru di `res/values*/strings_manga.xml` dalam 4 bahasa (kunci `manga_*`), dijaga `StringsCompletenessTest`.
- Room versi 5 lewat `MIGRATION_4_5` (hanya `CREATE TABLE`/`CREATE INDEX`); data lama tidak berubah.
- `BackupCodec.FORMAT = 2`; file format 1 tetap bisa dipulihkan.
- Atribusi MangaDex di detail dan reader (nama grup scanlation di reader). Tanpa iklan.
- Robolectric: `@Config(sdk = [35], qualifiers = "id", application = android.app.Application::class)`.
- Verifikasi: `bash /home/sakamoto/Data/Github/fuwanime-quick-wins/.superpowers/quick-wins/ci-test.sh` (unit test + `assembleRelease`). Tanpa QA emulator. Merge ke fork setelah CI hijau.
- Commit Bahasa Indonesia konvensional, tanpa baris co-author/atribusi Claude.

## Review Focus

- **Judul tanpa chapter yang bisa dibaca** (semua eksternal, atau `pages = 0`): detail harus menampilkan chapter eksternal sebagai tautan dan pesan bila tidak ada sama sekali, bukan tombol "Mulai baca" yang gagal. → test `pickChaptersKeepsExternal` + `firstReadable` di Task 1.
- **`baseUrl` MangaDex@Home kedaluwarsa** saat pengguna lama di satu chapter: gambar 403 → ambil ulang server, bukan layar rusak. → Task 2 `pages()` dengan parameter `forceRefresh`; test `pagesRefetchedAfterExpiry`.
- **429 dari MangaDex** saat scroll cepat: satu ulangan setelah `Retry-After`, lalu galat yang bisa dicoba ulang. → test `retriesOnceOn429` di Task 2.
- **Backup format 1 lama** setelah update: harus tetap dipulihkan. → test `formatOneStillDecodes` di Task 3.
- **Nomor chapter desimal / kosong** ("10.5", oneshot `null`): urutan dan next/previous benar. → test `pickChaptersOrdersNumerically`, `nextChapterAtEnd` di Task 1.

```kotlin
interface MangaDexApi {  // Retrofit; @Query dengan nama array "includes[]" dsb.
    @GET("manga") suspend fun mangaList(@QueryMap(encoded = true) params: Map<String, String>, @Query("includes[]") includes: List<String> = listOf("cover_art"), ...): MangaListDto
    @GET("manga/{id}") suspend fun manga(@Path("id") id: String, @Query("includes[]") includes: List<String> = listOf("cover_art", "author")): MangaEntityDto
    @GET("manga/{id}/feed") suspend fun feed(@Path("id") id: String, @Query("offset") offset: Int, ...): FeedDto
    @GET("at-home/server/{chapterId}") suspend fun atHome(@Path("chapterId") chapterId: String): AtHomeDto
    @GET("manga/tag") suspend fun tags(): TagListDto
    companion object { fun create(client: OkHttpClient, baseUrl: String = "https://api.mangadex.org/"): MangaDexApi }
}
class RateLimitInterceptor(private val perSecond: Int = 4, private val clock: () -> Long = System::nanoTime, private val sleep: (Long) -> Unit = Thread::sleep) : Interceptor
enum class MangaOrder { POPULAR, LATEST }   // order[followedCount]=desc | order[latestUploadedChapter]=desc
data class MangaPage(val items: List<Manga>, val total: Int, val offset: Int)
class MangaRepository(private val api: MangaDexApi, private val appLanguage: () -> String, private val now: () -> Long = System::currentTimeMillis) {
    suspend fun browse(order: MangaOrder, query: String = "", tagIds: List<String> = emptyList(), status: MangaStatus? = null, offset: Int = 0): MangaPage
    suspend fun detail(id: String): Manga
    suspend fun chapters(id: String): List<MangaChapter>          // semua halaman feed (limit 500), lalu pickChapters(chapterLanguageFor(appLanguage()))
    suspend fun pages(chapterId: String, dataSaver: Boolean, forceRefresh: Boolean = false): List<String>  // cache baseUrl 14 menit per chapter
    suspend fun tags(): List<MangaTag>                              // cache per proses
}
```

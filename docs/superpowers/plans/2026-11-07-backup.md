# Backup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Data user (favorit, riwayat, statistik harian, riwayat cari, pengaturan) tersimpan sebagai `fuwanime-backup.json` di folder pilihan user, otomatis harian, dan bisa dipulihkan setelah app dihapus lalu dipasang ulang.

**Architecture:** Paket baru `data/backup/` berisi logika murni (codec JSON Moshi, aturan gabung, filter kunci, aturan timpa) dan `BackupRepository` yang membaca/menulis lewat Storage Access Framework. `BackupWorker` (WorkManager) menjalankan backup harian. UI: bagian "Cadangan" di Pengaturan dan banner pulihkan sekali di Beranda, berbagi satu composable alur pulihkan.

**Tech Stack:** Kotlin, Room (`withTransaction`), DataStore Preferences, Moshi codegen (ksp, sudah terpasang), WorkManager, SAF (`OpenDocumentTree`, `OpenDocument`, `DocumentsContract`), JUnit4.

**Spec:** `docs/superpowers/specs/2026-11-07-statistik-backup-bahasa-design.md` — Sub-proyek 2.

## Global Constraints

- Tidak ada dependensi baru (tanpa `androidx.documentfile`, tanpa Google Drive SDK).
- Tidak ada perubahan skema Room (hanya query DAO baru) → tidak ada migrasi.
- File: `fuwanime-backup.json`, UTF-8, `"format": 1`, `"app": "fuwanime"`.
- Tidak dicadangkan: `downloads`, `anime_link`.
- Kunci pengaturan yang tidak ikut: `update_last_check_ms`, `update_dismissed_tag`, `notify_baseline_*`, `backup_*`.
- Pada galat pulihkan tidak ada data yang diubah.
- Teks Bahasa Indonesia hard-coded (dipindah di sub-proyek 3).
- Verifikasi: `bash /home/sakamoto/Data/Github/fuwanime-quick-wins/.superpowers/quick-wins/ci-test.sh`. Tanpa QA emulator. Merge ke fork setelah CI hijau.
- Commit tanpa baris co-author Claude.

## Review Focus

- **Backup kosong menimpa backup bagus.** Install ulang → pilih folder yang sudah berisi backup lama → backup otomatis langsung jalan dengan DB kosong dan menimpa file lama. Harus: bila DB lokal kosong dan file sudah ada, jangan tulis; tawarkan pulihkan. → test `shouldWriteBackup` di Task 3.
- **Pulihkan dua kali tidak menggandakan statistik.** `watch_daily` digabung dengan `max`, bukan jumlah. → test `mergeDailyIsIdempotent` di Task 1.
- **File dari versi lebih baru / rusak / bukan fuwanime** ditolak tanpa mengubah data. → test di Task 2; Task 3 hanya menulis ke DB setelah `decode` sukses.
- **Izin folder dicabut** (folder dihapus, app data di-clear): worker tidak crash/retry tanpa henti; Pengaturan menampilkan galat. → Task 4 menangkap `SecurityException`/`FileNotFoundException`, `Result.failure()`.
- **R8 rilis**: adapter Moshi codegen untuk entity Room dan kelas backup harus tetap ada setelah minify; kalau hilang, backup gagal hanya di build rilis. → Task 2 menambah keep rule; diverifikasi dengan `assembleRelease` + test codec di debug.

### Task 2: Format file (codec) + filter kunci pengaturan

**Files:**
- Create: `app/src/main/java/com/fuwanime/data/backup/BackupCodec.kt`
- Modify: `app/src/main/java/com/fuwanime/data/local/FuwaDatabase.kt` (tambah `@JsonClass(generateAdapter = true)` pada `FavoriteEntity`, `WatchHistoryEntity`, `SearchHistoryEntity`)

- Modify: `app/proguard-rules.pro`
- Test: `app/src/test/java/com/fuwanime/BackupCodecTest.kt`

**Interfaces:**
- Produces:
  - `@JsonClass(generateAdapter = true) data class SettingEntry(val key: String, val type: String, val value: String)` — `type` ∈ `"string" | "boolean" | "int" | "long" | "double"`, `value` disimpan sebagai string.
  - `@JsonClass(generateAdapter = true) data class BackupFile(val format: Int = 1, val app: String = "fuwanime", val createdAt: Long, val favorites: List<FavoriteEntity>, val history: List<WatchHistoryEntity>, val watchDaily: List<WatchDailyEntity>, val searches: List<SearchHistoryEntity>, val settings: List<SettingEntry>)`
  - `sealed interface BackupResult { data class Ok(val file: BackupFile) : BackupResult; data object TooNew : BackupResult; data object Corrupt : BackupResult }`
  - `object BackupCodec { const val FORMAT = 1; const val FILE_NAME = "fuwanime-backup.json"; fun encode(file: BackupFile): String; fun decode(json: String): BackupResult }`
    - `decode`: parse dulu hanya `format`/`app` via `JsonReader` atau adapter `Map`; `app != "fuwanime"` → `Corrupt`; `format > FORMAT` → `TooNew`; parse penuh gagal (`JsonDataException`, `IOException`, `null`) → `Corrupt`.
  - `fun isBackedUpSetting(key: String): Boolean` — false untuk `update_last_check_ms`, `update_dismissed_tag`, awalan `notify_baseline_`, awalan `backup_`.

- [ ] **Step 1: Test yang gagal** — `BackupCodecTest`:
  - `roundTripKeepsEverything`: `BackupFile` dengan 1 baris tiap daftar + 2 `SettingEntry` → `decode(encode(f)) == Ok(f)`.
  - `newerFormatIsTooNew`: `encode(f).replace("\"format\":1", "\"format\":2")` → `TooNew`.
  - `truncatedIsCorrupt`: `encode(f).dropLast(10)` → `Corrupt`.
  - `otherAppIsCorrupt`: `"app":"fuwanime"` diganti `"app":"lain"` → `Corrupt`.
  - `emptyStringIsCorrupt`: `decode("")` → `Corrupt`.
  - `settingFilter`: `isBackedUpSetting("theme_mode")`, `("op_start_123")`, `("favorite_sort")` true; `("update_last_check_ms")`, `("update_dismissed_tag")`, `("notify_baseline_9")`, `("backup_tree_uri")` false.

Simpan `setBackupResult(now, null)` atau `setBackupResult(null-tetap, pesan)` dengan pesan "Folder tidak bisa diakses — pilih ulang" untuk `SecurityException`/`FileNotFoundException`/`IllegalArgumentException`, selain itu "Gagal mencadangkan: ${e.message}". Semua IO di `Dispatchers.IO`.
    - `suspend fun read(uri: Uri): BackupResult` — baca teks (maks 20 MB; lebih → `Corrupt`), `BackupCodec.decode`.
    - `suspend fun restore(file: BackupFile)` — `library.restore(file)` lalu `settings.importSettings(file.settings)`.
    - `fun hasBackupInTree(): Boolean` tidak diperlukan publik (internal).

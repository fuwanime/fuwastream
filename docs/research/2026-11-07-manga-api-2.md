# Laporan Riset Komprehensif: Integrasi Multi-Sumber Manga Gratis untuk Native In-App Reader Android

**Tanggal Riset:** November 2026  
**Target Platform:** Android (Kotlin, OkHttp, Retrofit, Moshi, Jetpack Compose, Coil)  
**Dokumen Pendahulu:** `manga-api-research.md` (Analisis MangaDex v5, AniList, MAL, Consumet)  
**Tujuan Dokumen:** Menemukan dan membedah sumber manga **100% GRATIS** tambahan yang dapat diambil berkas gambar halamannya (*chapter page images*) untuk dirender secara **murni native** di dalam aplikasi (tanpa WebView, tanpa redirect ke browser luar), guna menyelesaikan keterbatasan MangaDex (chapter berlisensi yang hanya berisi `externalUrl` seperti MANGA Plus, serta judul berhalaman 0), dengan cakupan utama Bahasa Indonesia (`id`) dan Bahasa Inggris (`en`).

---

## 1. Ringkasan Eksekutif & Identifikasi Masalah Nyata

### 1.1 Kendala Operasional MangaDex API v5
Pada implementasi tahap pertama, aplikasi Android mengandalkan **MangaDex API v5** sebagai penyedia bacaan manga. Dalam pengujian nyata, ditemukan dua kendala struktural utama:
1. **Masalah Lisensi & External URL (The MangaPlus/Official Chapter Dilemma):**  
   Untuk judul-judul shonen dan seinen terpopuler di dunia (seperti *One Piece*, *Jujutsu Kaisen*, *Chainsaw Man*, *Dandadan*, *Spy x Family*, *Kaiju No. 8*, *Boruto: Two Blue Vortex*), MangaDex tidak menyimpan berkas gambar chapter rilis resmi (*simulpub*) di server MangaDex@Home karena alasan hak cipta. Sebagai gantinya, endpoint `/manga/{id}/feed` mengembalikan atribut `externalUrl` (misalnya mengarah ke `https://mangaplus.shueisha.co.jp/...`) dan nilai `pages: 0`. Akibatnya, aplikasi terpaksa membuka browser luar atau Android Custom Tabs. Pemilik aplikasi menetapkan aturan mutlak: **seluruh pengalaman membaca wajib berlangsung di dalam aplikasi secara native tanpa pernah melempar pengguna ke browser eksternal**.
2. **Sensor DNS ISP Indonesia (Internet Positif):**  
   Domain `api.mangadex.org` dan CDN gambar `uploads.mangadex.org` terkena blokir TrustPositif/Kominfo di beberapa penyedia ISP seluler dan fixed broadband Indonesia. Meskipun masalah ini telah diatasi pada level client menggunakan **DNS-over-HTTPS (DoH)** (seperti Cloudflare `1.1.1.1` atau Google `8.8.8.8` via `okhttp3.dnsoverhttps`), ketergantungan pada satu sumber tunggal menciptakan titik kegagalan tunggal (*single point of failure*).

### 1.2 Sasaran Riset Tahap 2
Riset ini berfokus pada sumber alternatif yang memenuhi kriteria ketat berikut:
* **Zero Cost (100% Gratis):** Tidak memerlukan biaya langganan, billing kartu kredit, atau API key berbayar.
* **Direct In-App Rendering (No WebView):** Endpoint wajib mengembalikan daftar URL berkas gambar (JPEG, PNG, WebP) yang dapat langsung diunduh oleh OkHttp dan dirender menggunakan Coil di Jetpack Compose.
* **Client-Only Independence:** Berjalan langsung dari aplikasi Android tanpa mewajibkan pembangunan dan pemeliharaan server perantara (*zero backend server*).
* **Cakupan Judul Populer:** Menyediakan judul-judul populer seperti *One Piece*, *Jujutsu Kaisen*, *Chainsaw Man*, *Solo Leveling*, *Frieren*, dan komik webtoon ternama dalam Bahasa Indonesia (`id`) dan Bahasa Inggris (`en`).

## 2. Analisis Mendalam: MANGA Plus by Shueisha API

MANGA Plus adalah platform resmi dari Shueisha yang merilis bab-bab manga mingguan secara simultan (*simulpub*) dengan majalah *Weekly Shonen Jump* di Jepang. Ekosistem pembaca komik open-source (seperti Tachiyomi, Mihon, Keiyoushi, dan Kotatsu) telah lama membedah API backend resmi ini.

```
+-----------------------------------------------------------------------------------+
|                        ALUR NATIVE READER MANGA PLUS                              |
+-----------------------------------------------------------------------------------+
  1. GET /api/title_detailV3?title_id={id}&clang=ind
     Headers: SESSION-TOKEN: <uuid>
     Response: Binary Protobuf (MangaPlusResponse) -> Parse TitleDetailView & Chapters
  2. GET /api/manga_viewer_v3?chapter_id={id}&split=yes&img_quality=super_high
     Response: Binary Protobuf -> Parse MangaViewer (view_token, image_url, encryption_key)
  3. OkHttp GET image_url
     Headers: Plus-Vw-Token: <view_token>
     Response Body: Encrypted Image Bytes (XOR Scrambled)
  4. OkHttp Interceptor: imageBytes.decodeXorCipher(encryption_key)
     Output: Plain JPEG/PNG Binary -> Coil SubcomposeAsyncImage (Jetpack Compose UI)
+-----------------------------------------------------------------------------------+
```

### 2.1 Endpoint, Arsitektur Jaringan, dan Header
* **Base WebAPI URL:** `https://jumpg-webapi.tokyo-cdn.com/api`
* **CDN Gambar:** `https://jumpg-webapi.tokyo-cdn.com` dan Akamai Edge servers.
* **Format Respons:** **Murni Protocol Buffers (Protobuf)**.  
  *Catatan Kritis:* Dahulu API ini mendukung parameter query `format=json`. Namun, per pembaruan infrastruktur Shueisha, seluruh pemanggilan dengan `format=json` langsung ditolak dengan status **HTTP 403 Forbidden**. Klien Android wajib menerima dan mem-parsing byte stream biner Protobuf.
* **Header Wajib untuk Panggilan API:**
  ```http
  SESSION-TOKEN: 8f2c3b4a-5e1d-4f8a-9c2b-1a2b3c4d5e6f
  User-Agent: Mozilla/5.0 (Linux; Android 14; Pixel 8) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/130.0.0.0 Mobile Safari/537.36
  Accept: */*
  ```
  Nilai `SESSION-TOKEN` cukup digenerasikan sekali saat inisialisasi aplikasi menggunakan `UUID.randomUUID().toString()`.
* **Header Wajib untuk Pengunduhan Berkas Gambar:**
  ```http
  Plus-Vw-Token: <view_token_dari_manga_viewer>
  User-Agent: Mozilla/5.0 ...
  ```
  Server CDN gambar memvalidasi token sesi pembacaan ini. Tanpa header `Plus-Vw-Token`, request gambar akan mengembalikan **HTTP 403 Forbidden**.

### 2.2 Katalog Endpoint Utama
1. **Daftar Seluruh Judul (All Titles):**
   * *Path:* `GET /api/title_list/allV2`
   * *Fungsi:* Mengembalikan seluruh komik yang terdaftar, dikelompokkan berdasarkan seri induk (*work*) yang memuat edisi dalam berbagai bahasa.
2. **Katalog Terfilter & Genre (All Titles with Genres):**
   * *Path:* `GET /api/title_list/all_v3?type=serializing&lang=eng&clang=eng`
   * *Parameter `type`:* `serializing` (sedang terbit), `completed` (tamat).
3. **Peringkat Komik Populer (Popular / Hottest):**
   * *Path:* `GET /api/title_list/rankingV2?lang=ind&type=hottest&clang=ind`
   * *Keterangan:* Mengembalikan judul terpopuler untuk bahasa yang dipilih (misal Bahasa Indonesia `ind` atau Inggris `eng`).
4. **Pembaruan Terbaru (Latest Updates / Web Home):**
   * *Path:* `GET /api/web/web_homeV4?lang=ind&clang=ind`
   * *Keterangan:* Mengembalikan banner unggulan dan chapter yang baru saja diunggah.
5. **Detail Komik & Daftar Chapter:**
   * *Path:* `GET /api/title_detailV3?title_id={title_id}&clang=ind`
   * *Contoh Judul:* `title_id=100020` (*Chainsaw Man*), `title_id=100037` (*One Piece*), `title_id=100034` (*Jujutsu Kaisen*).
6. **Viewer Chapter (Halaman Gambar & Kunci Dekripsi):**
   * *Path:* `GET /api/manga_viewer_v3?chapter_id={chapter_id}&split=yes&img_quality=super_high&clang=ind`
   * *Parameter:*
     * `split=yes`: Membelah halaman ganda ganda (*spread*) menjadi dua gambar tunggal agar nyaman dibaca pada layar smartphone vertikal.
     * `img_quality`: Pilihan kualitas resolusi (`low`, `high`, `super_high`). Direkomendasikan `super_high` untuk visual tajam di layar resolusi tinggi Android.

### 2.4 Algoritma Dekripsi Gambar (XOR Cipher Descrambling)
Untuk mencegah pengunduhan langsung gambar tanpa izin, MANGA Plus mengenkripsi byte gambar menggunakan sandi aliran XOR berbasis kunci heksadesimal (*hex-encoded key*).
* **Mekanisme:**
  1. Pada objek `MangaPage`, field `encryption_key` berisi string heksadesimal (misal `"a3f12c8b..."`). Jika string ini ada dan tidak kosong, berkas gambar terenkripsi.
  2. Kunci heksadesimal diubah menjadi urutan byte (`ByteArray`) dengan membaginya per 2 karakter lalu dikonversi ke nilai integer heksadesimal (`0x00` - `0xFF`).
  3. Setiap byte gambar hasil unduhan dikenakan operasi XOR dengan byte kunci secara berulang (*cyclic modulo*):
     $$\text{decryptedByte}[i] = \text{encryptedByte}[i] \oplus \text{keyBytes}[i \pmod{\text{keyBytes.size}}]$$
  4. Byte hasil XOR tersebut adalah berkas gambar murni (JPEG/PNG) yang valid dan siap dibaca oleh decoder bitmap Android.

#### Implementasi Lengkap dalam Kotlin (OkHttp Interceptor)
```kotlin
package com.app.manga.network

import okhttp3.Interceptor
import okhttp3.MediaType.Companion.toMediaTypeOrNull
import okhttp3.Response
import okhttp3.ResponseBody.Companion.toResponseBody

class MangaPlusImageInterceptor : Interceptor {
    override fun intercept(chain: Interceptor.Chain): Response {
        val request = chain.request()
        val fragment = request.url.fragment // Kunci dikirim melalui URL fragment: #key={hexKey}&vt={viewToken}
        
        // Ekstrak token sesi dan kunci enkripsi dari fragment URL
        val viewToken = extractFragmentParam(fragment, "vt")
        val encryptionKey = extractFragmentParam(fragment, "key")

        // Sisipkan header Plus-Vw-Token jika viewToken tersedia
        val modifiedRequest = if (!viewToken.isNullOrEmpty()) {
            request.newBuilder()
                .header("Plus-Vw-Token", viewToken)
                .build()
        } else {
            request
        }

        val response = chain.proceed(modifiedRequest)
        if (!response.isSuccessful || encryptionKey.isNullOrEmpty()) {
            return response
        }

        // Baca payload terenkripsi
        val encryptedBytes = response.body?.bytes() ?: return response
        val contentType = response.header("Content-Type") ?: "image/jpeg"

        // Dekripsi menggunakan XOR Cipher
        val decryptedBytes = decodeXorCipher(encryptedBytes, encryptionKey)

        // Kembalikan response body baru yang sudah terdekripsi
        return response.newBuilder()
            .body(decryptedBytes.toResponseBody(contentType.toMediaTypeOrNull()))
            .build()
    }

    private fun decodeXorCipher(data: ByteArray, hexKey: String): ByteArray {
        val keyBytes = hexKey.chunked(2)
            .map { it.toInt(16).toByte() }
            .toByteArray()

        val output = ByteArray(data.size)
        val keyLen = keyBytes.size
        for (i in data.indices) {
            output[i] = (data[i].toInt() xor keyBytes[i % keyLen].toInt()).toByte()
        }
        return output
    }

    private fun extractFragmentParam(fragment: String?, key: String): String? {
        if (fragment.isNullOrEmpty()) return null
        return fragment.split("&")
            .map { it.split("=", limit = 2) }
            .firstOrNull { it.size == 2 && it[0] == key }
            ?.get(1)
    }
}
```

### 2.5 Aturan Ketersediaan Chapter Gratis & Pembatasan
* **Kebijakan Chapter Gratis (WebAPI):**
  * Pada struktur `ChapterListGroup`, MANGA Plus membagi daftar bab menjadi tiga grup:
    1. `first_chapter_list`: Selalu gratis dan dapat dibaca kapan saja (umumnya Bab 1, 2, dan 3).
    2. `mid_chapter_list`: Bab-bab tengah. Pada WebAPI publik, bab ini berstatus kedaluwarsa (*expired*). Jika endpoint viewer dipanggil, API akan mengembalikan popup error: *"This chapter has expired"*.
    3. `last_chapter_list`: Selalu gratis untuk 3 bab rilis terbaru (*simulpub window*).
* **Fitur "First-Read Free" di Aplikasi Resmi vs WebAPI:**  
  Aplikasi mobile resmi MANGA Plus memiliki kampanye di mana pengguna dapat membaca bab tengah satu kali secara gratis dengan mendaftarkan ID perangkat (`device_secret`). Namun, untuk integrasi *stateless guest* tanpa kerumitan reverse-engineering enkripsi registrasi perangkat Shueisha yang dinamis, WebAPI menjamin ketersediaan **Bab 1-3** dan **3 Bab Terbaru** secara instan dan legal.
* **Cakupan Bahasa:**
  * **Bahasa Indonesia (`ind`, ID: 3):** Judul-judul Shonen Jump utama memiliki terjemahan resmi Bahasa Indonesia, termasuk *One Piece*, *Jujutsu Kaisen*, *Chainsaw Man*, *Spy x Family*, *Kaiju No. 8*, *Dandadan*, dan *Boruto: Two Blue Vortex*.
  * **Bahasa Inggris (`eng`, ID: 0):** Seluruh katalog MANGA Plus (ratusan judul) tersedia lengkap dalam Bahasa Inggris.
* **Rate Limit & Stabilitas:**
  * Rate limit aman: **1 request per detik** untuk endpoint metadata API, dan **2 request per detik** untuk CDN gambar.
  * Uptime mencapai 99.9% karena di-host pada jaringan Akamai Tokyo CDN resmi. Tidak pernah diblokir oleh TrustPositif Indonesia.

### 3.1 Pembedahan Teknis: LINE Webtoon API (Naver)
LINE Webtoon adalah sumber resmi terbaik di dunia untuk kategori Manhwa dan Webcomic vertikal.
1. **Endpoint JSON Daftar Episode (Mobile API):**
   * *URL:* `https://m.webtoons.com/api/v1/{type}/{titleNo}/episodes?pageSize=99999`
   * *Parameter:*
     * `type`: `"webtoon"` (rilis orisinal resmi) atau `"canvas"` (karya kreator independen).
     * `titleNo`: Nomor ID seri (misal `titleNo=1049`).
     * Jika `type=canvas`, tambahkan query `readingLanguageCode=id`.
   * *Header Wajib:*
     ```http
     Referer: https://m.webtoons.com/
     User-Agent: Mozilla/5.0 (Linux; Android 14; Mobile) ...
     ```
   * *Respon:* JSON murni (`EpisodeListResponse`) yang memuat nomor bab, judul bab, thumbnail, tanggal rilis, dan tautan viewer webtoon.
2. **Pengambilan Berkas Gambar Halaman (Viewer Scraper):**
   * *URL Bab:* `https://www.webtoons.com/{lang}/.../viewer?title_no={id}&episode_no={ep}`
   * *Selektor Jsoup:* `div#_imageList > img`
   * *Atribut URL Gambar:* `data-url` pada masing-masing tag `<img>`.
   * *Optimalisasi Kualitas Gambar:* Hapus parameter query `?type=q90` pada URL gambar untuk mengunduh versi kualitas visual maksimum tanpa kompresi agresif.
3. **Aturan Hotlink & Proteksi CDN Gambar Naver:**
   * CDN gambar LINE Webtoon (`*.pstatic.net` atau `*.webtoons.com`) menerapkan inspeksi header HTTP secara ketat.
   * **Aturan Kritis:** Client OkHttp/Coil **wajib** menyertakan header `Referer: https://www.webtoons.com/` pada saat mengunduh berkas gambar. Tanpa header Referer yang sesuai, server CDN langsung membalas dengan **HTTP 403 Forbidden**.

## 4. Analisis Scanlation Aggregator: Indonesia & Internasional

Scanlation aggregator mengindeks komik bajakan hasil terjemahan komunitas. Keunggulan mutlaknya adalah ketersediaan seluruh bab lengkap (dari bab 1 sampai bab paling akhir) untuk judul-judul berlisensi yang dikunci di MangaDex dan MangaPlus.

### 4.1 Agregator Bahasa Indonesia (`id`)

#### A. Shinigami API (`api.shngm.io`)
Shinigami adalah salah satu portal scanlation terbesar di Indonesia yang berfokus pada Manhwa (seperti *Solo Leveling*, *Omniscient Reader*, *Nano Machine*) serta Manga populer. Berbeda dengan situs komik lain yang hanya menyediakan antarmuka web, Shinigami memiliki **REST API JSON murni** yang sangat terstruktur:
* **Base API URL:** `https://api.shngm.io`
* **Format Respons:** JSON Murni (Tanpa HTML parsing).
* **Header Wajib:**
  ```http
  Accept: application/json
  DNT: 1
  Sec-GPC: 1
  User-Agent: Mozilla/5.0 ...
  ```
* **Katalog Endpoint:**
  1. *Daftar Komik Populer:*  
     `GET https://api.shngm.io/v1/manga/list?page=1&page_size=30&sort=popularity`
  2. *Daftar Komik Rilis Terbaru:*  
     `GET https://api.shngm.io/v1/manga/list?page=1&page_size=30&sort=latest`
  3. *Pencarian Komik:*  
     `GET https://api.shngm.io/v1/manga/list?page=1&page_size=30&q={query}`
  4. *Detail Komik (Sinopsis, Cover, Penulis, Status):*  
     `GET https://api.shngm.io/v1/manga/detail/{mangaId}`
  5. *Daftar Bab (Chapter List):*  
     `GET https://api.shngm.io/v1/chapter/{mangaId}/list?page_size=3000`
  6. *Halaman Gambar Bab:*  
     `GET https://api.shngm.io/v1/chapter/detail/{chapterId}`
     *Respon JSON:*
     ```json
     {
       "retcode": 200,
       "data": {
         "baseUrl": "https://storage.shngm.id",
         "chapterPage": {
           "path": "/data/chapters/12345/",
           "pages": ["01.jpg", "02.jpg", "03.jpg"]
         }
       }
     }
     ```
     *Konstruksi URL Gambar:* `${baseUrl}${chapterPage.path}${imageName}`
* **Proteksi Cloudflare:** Endpoint API (`api.shngm.io`) tidak menerapkan Turnstile / bot challenge sehingga dapat diakses langsung oleh client OkHttp Android.

#### B. WestManga (`westmanga.cc`)
WestManga adalah portal scanlation Indonesia legendaris dengan basis komik yang sangat luas. WestManga telah memodernisasi arsitekturnya dengan menyediakan REST API JSON internal:
* **Base URL:** `https://westmanga.cc` (Domain aktif saat ini, berganti dari `westmanga.info` dan `westmanga.tv`).
* **Mekanisme Kemanan (Visit Token):**
  Untuk mencegah crawling liar, WestManga mewajibkan header `X-WM-Visit`.
  * *Cara Memperoleh Token:*  
    Lakukan request: `GET https://westmanga.cc/api/visit-token`. Server merespon dengan JSON `{ "status": true, "token": "wm_token_abc...", "expiresAt": 1731000000 }`.
  * Token ini valid selama 1 jam dan cukup disimpan pada cache memori OkHttp Interceptor.
* **Katalog Endpoint REST API:**
  1. *Pencarian & Katalog:*  
     `GET https://westmanga.cc/api/contents?page=1&per_page=20&type=Comic&q={query}`  
     (Gunakan `SortFilter` untuk populer dan rilis terbaru).
  2. *Detail Komik:*  
     `GET https://westmanga.cc/api/comic/{slug}` -> Mengembalikan metadata komik dan seluruh array daftar bab.
  3. *Halaman Gambar Bab:*  
     `GET https://westmanga.cc/api/v/{chapterSlug}` -> Mengembalikan array URL gambar: `{ "data": { "images": ["https://.../01.jpg", "/uploads/.../02.jpg"] } }`.
* **Keunggulan:** Respon JSON murni memudahkan pemetaan DTO menggunakan Moshi/Kotlinx.Serialization tanpa perlu Jsoup.

#### C. Komiku (`komiku.org`)
* **Base URL:** `https://komiku.org` (Domain resmi aktif saat ini, menggantikan `komiku.id` dan `komiku.co.id`).
* **Format:** Dokumen HTML (Memerlukan Jsoup Parser).
* **Selektor Elemen Utama:**
  * *Katalog:* `div.bge` -> Link `a:has(h3)`, Judul `h3`, Cover `img[src]`.
  * *Daftar Chapter:* `#Daftar_Chapter tr:has(td.judulseries)` -> Link `a`, Nama `a.text()`.
  * *Halaman Gambar:* `#Baca_Komik img` (Filter elemen promosi yang memuat `komiku-promosi`).
* **Aturan Hotlinking Gambar:**  
  CDN gambar Komiku (`img.komiku.org`, `thumbnail.komiku.org`) menerapkan verifikasi anti-hotlinking. Request pengunduhan gambar dari OkHttp/Coil **wajib** menyertakan:
  ```http
  Referer: https://komiku.org/
  Accept: image/avif,image/webp,image/apng,image/*,*/*;q=0.8
  ```

#### D. Evaluasi Komikcast, Kiryuu, dan Mangaku
* **Komikcast:** Mengalami perubahan struktur website drastis dan berganti merek/domain ke `VoraToon` (`komikcast05` / `voratoon.me`). Sering memicu kendala migrasi pada basis data lokal pengguna.
* **Kiryuu:** Mengalami *domain churn* paling ekstrem di Indonesia (berganti berkali-kali dari `kiryuu.id` $\to$ `kiryuu02.com` $\to$ `kiryuu03.com` $\to$ `v7.kiryuu.to`). Selain itu, domain-domain Kiryuu menerapkan Cloudflare Turnstile CAPTCHA secara ketat yang memblokir client OkHttp native murni dengan respons HTTP 403 / Cloudflare Challenge.
* **Mangaku:** Menyisipkan script pengabur kode (*JavaScript obfuscation*) dan anti-adblock yang membuat parsing HTML sangat rentan pecah.
* **Kesimpulan:** Komikcast, Kiryuu, dan Mangaku **tidak direkomendasikan** untuk integrasi native Android karena tingginya risiko *breakage* dan proteksi bot Cloudflare.

### 4.2 Agregator Bahasa Inggris (`en`)

#### A. Weeb Central (`weebcentral.com`)
Weeb Central adalah penerus spiritual resmi dari jaringan **MangaLife / MangaSee** yang legendaris (MangaLife resmi menghentikan operasinya pada awal 2025, dan pengelolaannya beralih ke Weeb Central). Dalam ekosistem Keiyoushi dan Kotatsu, Weeb Central saat ini diakui sebagai **agregator manga Bahasa Inggris terbaik dan paling stabil di dunia**.
* **Base URL:** `https://weebcentral.com`
* **Format:** HTML Responsif berbasis Tailwind CSS & Alpine.js yang sangat rapi.
* **Katalog Endpoint & Selektor Jsoup:**
  1. *Pencarian & Katalog Populer:*  
     `GET https://weebcentral.com/search/data?text={query}&limit=32&offset=0&display_mode=Full%20Display&sort=Popularity`  
     *Selektor Manga:* `article > section > a`  
     *Selektor Judul:* `div:not([class]):last-child`  
     *Selektor Cover:* `source[srcset]` (ganti resolusi `small` menjadi `normal`).
  2. *Daftar Bab Lengkap (Full Chapter List):*  
     `GET https://weebcentral.com/series/{seriesId}/full-chapter-list`  
     *Selektor Bab:* `div[x-data] > a`  
     *Keterangan Istimewa:* Weeb Central memuat penanda apakah suatu bab merupakan scanlation komunitas atau rilisan digital resmi (*Official Digital Volume Rips* dari Viz/Shueisha/Kodansha).
  3. *Halaman Gambar Bab:*  
     `GET https://weebcentral.com/chapters/{chapterId}/images?is_prev=False&reading_style=long_strip`  
     *Selektor Halaman:* `section[x-data~=scroll] > img` -> Atribut `abs:src`.
* **CDN Gambar & Hotlinking:**  
  Gambar di-host di server berkecepatan tinggi (`temp.compsci88.com` atau domain CDN terkait). Tidak memerlukan enkripsi XOR dan tidak meminta token sesi dinamis yang rumit. Cukup sertakan header `Host: {cdn_host}` standar.
* **Rate Limiting:** Terapkan rate limit **1 request per 2 detik** untuk menghormati server Weeb Central dan mencegah HTTP 429.
* **Kekuatan Utama:** Menyediakan **seluruh bab lengkap (Bab 1 sampai Bab Terbaru)** untuk *One Piece*, *Jujutsu Kaisen*, *Chainsaw Man*, *Solo Leveling*, dan *Frieren* dalam kualitas digital tertinggi.

#### B. MangaKakalot / Manganato (`chapmanganato.to` / `nelomanga.net`)
* **Status Domain:** Mengalami pergeseran domain berulang kali (`manganato.com` $\to$ `natomanga.com` $\to$ `nelomanga.net` / `chapmanganato.to`).
* **Format:** HTML Scraper (Jsoup).
* **Aturan Hotlink Gambar:** Sangat ketat. Server CDN (`*.cdndelivery.info`) akan mengembalikan gambar rusak (*placeholder error*) atau HTTP 403 jika header `Referer: https://chapmanganato.to/` tidak dikirimkan.
* **Kelemahan:** Frekuensi pergantian domain yang tinggi dan penempatan iklan agresif di HTML membuat parser sering mengalami *NullPointerException*.

#### C. Status Terkini ComicK Pasca-Penutupan
* Pada akhir 2025, domain resmi **ComicK (`comick.io`) resmi ditutup secara permanen** oleh pemiliknya menyusul tekanan hak cipta.
* Seluruh domain yang beredar saat ini (seperti `comick.live`, `comick.gg`, `comick.art`, `comick.is`) adalah **situs tiruan (clones / unoriginal)** yang tidak stabil, sering berganti domain harian, dan berpotensi menyuntikkan skrip berbahaya. Komunitas Keiyoushi secara resmi melabeli situs-situs ini sebagai *invalid/fake* dan menolak memasukkannya ke dalam repositori resmi.

## 5. Arsitektur Ekstensi Mihon/Keiyoushi & Panduan Porting Native Kotlin

Ekosistem Tachiyomi/Mihon/Keiyoushi tidak menggunakan satu kode monolithic, melainkan arsitektur ekstensi modular berbasis kelas dasar terstandarisasi.

### 5.1 Struktur Inti Ekstensi Keiyoushi
1. **`HttpSource`:** Kelas abstrak dasar pembungkus OkHttp. Mengelola konfigurasi client, interceptor, User-Agent, dan rate-limiter.
2. **`ParsedHttpSource`:** Turunan `HttpSource` yang mengotomatisasi pola *Scrape-and-Parse* HTML menggunakan Jsoup. Pengembang cukup mengimplementasikan metode selektor:
   * `popularMangaSelector()`, `popularMangaFromElement(element)`
   * `searchMangaSelector()`, `searchMangaFromElement(element)`
   * `mangaDetailsParse(document)`
   * `chapterListSelector()`, `chapterFromElement(element)`
   * `pageListParse(document)`
3. **`KeiSource`:** Format modern Keiyoushi berbasis Kotlin Coroutines murni (`suspend fun getPopularManga()`, `suspend fun getSearchMangaList()`, `suspend fun getPageList()`).
4. **Multisrc Themes (Generator Mesin Tema):**  
   Untuk menghindari penulisan ulang kode ribuan situs yang menggunakan CMS sejenis, Keiyoushi membuat mesin tema bersama (*multisrc*):
   * **`Madara`:** Tema WordPress manga terpopuler di dunia (menggunakan WP-JSON API atau ajax `admin-ajax.php`).
   * **`MangaThemesia`:** Tema WordPress komik Asia Tenggara (digunakan oleh puluhan scanlation lokal).
   * **`Mangabox`:** Mesin tema keluarga MangaKakalot/Manganato.
   * **`FoolSlide`:** Mesin tema klasik kelompok scanlation independen.

### 5.2 Mengapa Memuat Berkas APK Ekstensi Secara Dinamis Adalah Anti-Pattern
Beberapa pengembang Android tergoda untuk memuat file APK ekstensi Tachiyomi secara dinamis menggunakan `DexClassLoader`. Namun, untuk aplikasi Android modern, pendekatan ini memiliki kelemahan fatal:
* **Pelanggaran Kebijakan Google Play:** Memuat biner DEX/APK dari luar aplikasi melanggar *Google Play Malicious Behavior Policy*.
* **Overhead Komputasi & Dependency Hell:** Ekstensi Tachiyomi bergantung pada kelas-kelas internal (`eu.kanade.tachiyomi.source.*`) yang harus di-shim atau di-mocking secara rumit.
* **Stabilitas Eksekusi:** Crash pada kode ekstensi pihak ketiga dapat mematikan proses utama aplikasi (*uncaught JVM exception*).

#### B. Konfigurasi Coil ImageLoader untuk Multi-Sumber
Coil perlu mengetahui header khusus (`Referer`, `Plus-Vw-Token`) atau proses dekripsi byte saat memuat gambar bab:

```kotlin
package com.app.manga.ui.reader

import android.content.Context
import coil.ImageLoader
import coil.request.ImageRequest
import com.app.manga.network.MangaPlusImageInterceptor
import okhttp3.OkHttpClient
import java.util.concurrent.TimeUnit

fun createMangaImageLoader(context: Context, okHttpClient: OkHttpClient): ImageLoader {
    val specializedClient = okHttpClient.newBuilder()
        .addInterceptor(MangaPlusImageInterceptor()) // Menangani XOR descrambler MANGA Plus
        .addInterceptor { chain ->
            val request = chain.request()
            val url = request.url.toString()
            val builder = request.newBuilder()

            // Sisipkan Referer otomatis berdasarkan host target gambar
            when {
                url.contains("pstatic.net") || url.contains("webtoons.com") -> {
                    builder.header("Referer", "https://www.webtoons.com/")
                }
                url.contains("komiku.org") -> {
                    builder.header("Referer", "https://komiku.org/")
                }
                url.contains("cdndelivery.info") || url.contains("manganato.com") -> {
                    builder.header("Referer", "https://chapmanganato.to/")
                }
            }
            chain.proceed(builder.build())
        }
        .connectTimeout(15, TimeUnit.SECONDS)
        .readTimeout(20, TimeUnit.SECONDS)
        .build()

    return ImageLoader.Builder(context)
        .okHttpClient(specializedClient)
        .respectCacheHeaders(false) // Maksimalkan disk cache untuk kenyamanan membaca offline
        .build()
}
```

### 7.1 Peringkat 1 (Top Pick - Official & Legal): **MANGA Plus by Shueisha**
* **Alasan Pemilihan Utama:**  
  Menyelesaikan akar masalah pertama MangaDex secara langsung. Ketika MangaDex mengembalikan `externalUrl` untuk *One Piece*, *Jujutsu Kaisen*, *Chainsaw Man*, *Dandadan*, *Spy x Family*, atau *Boruto*, aplikasi tidak perlu lagi melempar pengguna ke browser. Aplikasi cukup mengambil `chapterId` dari tautan MangaPlus tersebut (atau memanggil endpoint pencarian MangaPlus), memanggil `/api/manga_viewer_v3`, mendekripsi byte XOR secara native, dan merendernya seketika di reader Jetpack Compose.
* **Bahasa:** Mendukung Bahasa Indonesia (`ind`) dan Bahasa Inggris (`eng`).
* **Keunggulan:** 100% legal, server Akamai CDN resmi super cepat, tidak pernah terblokir Internet Positif, dan nol risiko proteksi Cloudflare Turnstile.
* **Catatan Implementasi:** Wajib memasang parser Protobuf ringan (bisa menggunakan pustaka **Wire by Square** atau kelas proto terkompilasi) dan menyematkan `MangaPlusImageInterceptor` untuk dekripsi XOR pada Coil.

### 7.2 Peringkat 2 (Best English Full Archive): **Weeb Central**
* **Alasan Pemilihan Utama:**  
  Menyelesaikan kelemahan bab tengah (*expired mid-chapters*) pada MangaPlus dan bab yang terkena DMCA di MangaDex. Weeb Central menyimpan **seluruh bab lengkap dari nomor 1 hingga nomor paling baru** untuk hampir seluruh komik di dunia dalam Bahasa Inggris dengan kualitas digital resmi (*official rips*).
* **Keunggulan:** Struktur HTML Tailwind CSS yang sangat bersih dan konsisten, tidak memicu CAPTCHA bot jika diberi jeda wajar (1 request per 2 detik), dan URL gambar dapat langsung diunduh tanpa skema dekripsi rumit.
* **Catatan Implementasi:** Gunakan pustaka **Jsoup** (`org.jsoup:jsoup:1.18.3`) untuk mem-parse HTML respons ke dalam data class Kotlin.

### 7.3 Peringkat 3 (Best Indonesian Full Archive): **Shinigami API (`api.shngm.io`)**
* **Alasan Pemilihan Utama:**  
  Portal terlengkap di Indonesia untuk judul-judul Manhwa Korea (*Solo Leveling*, *Tower of God*, *Lookism*, *Omniscient Reader*) dan Manga terjemahan Bahasa Indonesia dengan bab lengkap 1 sampai tamat.
* **Keunggulan Mutlak:** Memiliki **REST API JSON murni** (`/v1/manga/...`, `/v1/chapter/...`). Pengembang tidak perlu menulis scraper HTML yang rentan rusak saat layout web berubah. Seluruh respon dapat langsung di-mapping ke DTO Moshi / Kotlinx.Serialization.
* **Catatan Implementasi:** Sisipkan DoH (DNS-over-HTTPS) pada client OkHttp agar panggilan ke domain `api.shngm.io` dan CDN gambarnya kebal terhadap sensor ISP lokal Indonesia.

### 7.4 Opsi Pelengkap Khusus Webtoon: **LINE Webtoon Mobile API**
* Jika aplikasi ingin menonjolkan katalog webtoon orisinal (*Tower of God*, *Lookism*, *Noblesse*, *Marry My Husband*, *True Beauty*) secara 100% legal dalam Bahasa Indonesia dan Inggris, integrasikan LINE Webtoon menggunakan kombinasi endpoint JSON mobile (`m.webtoons.com/api/v1`) dan selektor gambar Jsoup dengan header wajib `Referer: https://www.webtoons.com/`.

### 8.2 Cuplikan Kode Client OkHttp Bersama dengan DoH & Interceptors
```kotlin
package com.app.manga.network

import okhttp3.HttpUrl.Companion.toHttpUrl
import okhttp3.OkHttpClient
import okhttp3.dnsoverhttps.DnsOverHttps
import java.io.File
import java.net.InetAddress
import java.util.concurrent.TimeUnit

object NetworkModule {
    fun provideOkHttpClient(cacheDir: File): OkHttpClient {
        val baseBuilder = OkHttpClient.Builder()
            .connectTimeout(15, TimeUnit.SECONDS)
            .readTimeout(20, TimeUnit.SECONDS)

        // 1. Konfigurasi DNS-over-HTTPS (Bypass Blokir Internet Positif Indonesia)
        val appDns = DnsOverHttps.Builder()
            .client(baseBuilder.build())
            .url("https://cloudflare-dns.com/dns-query".toHttpUrl())
            .bootstrapDnsHosts(
                InetAddress.getByName("1.1.1.1"),
                InetAddress.getByName("1.0.0.1")
            )
            .build()

        return baseBuilder
            .dns(appDns)
            // 2. Interceptor Dekripsi XOR Manga Plus
            .addInterceptor(MangaPlusImageInterceptor())
            // 3. Interceptor Referer Dinamis untuk CDN Gambar Naver/Komiku/Manganato
            .addInterceptor { chain ->
                val req = chain.request()
                val host = req.url.host
                val newReq = req.newBuilder()

                if (host.contains("pstatic.net") || host.contains("webtoons.com")) {
                    newReq.header("Referer", "https://www.webtoons.com/")
                } else if (host.contains("komiku.org")) {
                    newReq.header("Referer", "https://komiku.org/")
                } else if (host.contains("cdndelivery.info")) {
                    newReq.header("Referer", "https://chapmanganato.to/")
                }
                chain.proceed(newReq.build())
            }
            .build()
    }
}
```

### 8.3 Mitigasi Risiko & Kebijakan Distribusi Aplikasi
1. **Risiko Pemblokiran Akun Google Play Store:**  
   Menyediakan akses langsung ke server scanlation bajakan (*Weeb Central*, *Shinigami*, *WestManga*) secara terbuka di dalam biner APK yang diunggah ke Google Play Store melanggar kebijakan hak cipta (*IP Infringement Policy*).  
   *Strategi Rilis:*
   * **Distribusi Utama (Rekomendasi):** Rilis APK melalui **GitHub Releases**, **F-Droid**, atau situs web resmi aplikasi (seperti Tachiyomi, Mihon, dan Aniyomi).
   * **Jika Wajib Rilis di Google Play Store:** Jadikan aplikasi hanya sebagai *Anime & Manga Tracker* (menggunakan AniList dan MangaPlus resmi). Sediakan fitur "Tambah Sumber Komunitas" (*Custom Source Repository URL*) di menu Pengaturan sehingga pengguna memasukkan modul scanlation secara mandiri setelah aplikasi terinstal.
2. **Risiko Domain Churn pada Scraper:**  
   Domain situs agregator dapat berganti sewaktu-waktu. Jangan pernah melakukan *hardcode* string URL seperti `https://westmanga.cc` atau `https://komiku.org` di dalam biner aplikasi. Simpan base URL tersebut di dalam file konfigurasi JSON dinamis jarak jauh (misalnya di GitHub Gist atau Firebase Remote Config gratis). Jika domain berganti, cukup ubah string di Gist tanpa perlu merilis pembaruan APK ke pengguna.

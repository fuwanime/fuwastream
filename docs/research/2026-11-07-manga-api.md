# Laporan Riset Komprehensif: Manga API Gratis untuk Aplikasi Android (Kotlin / Jetpack Compose)

**Tanggal Riset:** November 2026  
**Target Platform:** Android (Kotlin, Retrofit, Moshi, OkHttp, Room, Jetpack Compose)  
**Dokumen Terkait:** Arsitektur Streaming Anime Eksisting (`https://xyz-api.animein.net`, AniList GraphQL, AniSkip)  
**Tujuan Dokumen:** Analisis teknis mendalam mengenai kandidat API manga yang **100% GRATIS** tanpa biaya langganan, tanpa paket berbayar, dan tanpa tagihan per-request, untuk menambahkan katalog manga, penelusuran (search & browse), detail informasi, daftar chapter, serta pembaca gambar (chapter page reader) berbahasa Indonesia (`id`) dan Inggris (`en`).

---

## 1. Ringkasan Eksekutif & Konteks Teknis

Aplikasi saat ini telah memiliki arsitektur modern berbasis Android Jetpack (Compose, Room, Retrofit, Moshi, OkHttp) yang mengonsumsi REST API gratis untuk streaming anime dan GraphQL untuk metadata (AniList). Integrasi modul manga menuntut kapabilitas serupa:
1. **Zero Cost Requirement:** Seluruh kandidat yang dianalisis harus murni gratis untuk digunakan dalam batas wajar pengembangan aplikasi publik, tanpa mewajibkan kartu kredit atau upgrade berbayar.
2. **Kebutuhan Fitur:**
   - Pencarian judul (Search).
   - Penjelajahan katalog (Browse: Populer, Rilis Terbaru/Latest, Filter Genre).
   - Informasi detail komik (Sinopsis, Cover, Genre, Status rilis, Penulis/Artis).
   - Daftar chapter yang terurut.
   - Daftar URL gambar per chapter untuk reader native di Jetpack Compose.
   - Ketersediaan terjemahan Bahasa Indonesia (`id`) dan Bahasa Inggris (`en`).
3. **Kemandirian Client (Direct Android Access):** Evaluasi apakah API dapat diakses langsung oleh client OkHttp di perangkat Android pengguna tanpa harus mendirikan backend server perantara (middle-tier proxy), terutama terkait proteksi Cloudflare, bot-detection, dan batas komputasi serverless.

Berdasarkan riset mendalam terhadap dokumentasi resmi, repositori terbuka ekosistem pembaca komik (seperti Tachiyomi, Mihon, dan Keiyoushi), serta uji respon endpoint langsung, kandidat dikelompokkan secara tegas menjadi dua kategori fungsional:
- **Full Reading Provider:** Menyediakan metadata sekaligus endpoint pengunduhan berkas gambar halaman chapter (MangaDex, Consumet, dan Scraper Komik Indonesia).
- **Metadata Only Provider:** Menyediakan data bibliografi yang kaya (sinopsis, cover HD, genre, rating, ranking), namun **tidak menyediakan halaman gambar komik** (AniList GraphQL, Jikan/MyAnimeList, Kitsu, MangaUpdates, dan ComicK pasca-migrasi).

### 2.1 MangaDex API (v5)

* **Kategori Fungsional:** **FULL READING (Menyediakan Halaman Chapter Gambar & Metadata Lengkap)**
* **Base URL:** `https://api.mangadex.org`
* **Dokumentasi Resmi:** [https://api.mangadex.org/docs/](https://api.mangadex.org/docs/)
* **Spesifikasi OpenAPI 3.0:** [https://api.mangadex.org/docs/static/api.yaml](https://api.mangadex.org/docs/static/api.yaml)
* **Status API:** Resmi (Officially Documented & Actively Maintained).

#### A. Mekanisme Otentikasi
* **None (100% Gratis & Terbuka untuk Konsumsi Publik):**
  Untuk membaca, mencari komik, mengambil daftar chapter, dan mengunduh gambar halaman melalui MangaDex@Home, API MangaDex **tidak memerlukan otentikasi, API Key, maupun token sama sekali**.
* Fitur OAuth 2.0 (Personal Client / Public Client) hanya disediakan jika aplikasi ingin mengakses fitur akun pengguna (sinkronisasi bookmark, riwayat baca, atau mengunggah chapter). Untuk mode guest reader, seluruh panggilan bersifat unauthenticated.

#### B. Endpoint, Contoh Request Path & Mapping JSON

1. **Pencarian Komik (Search):**
   * *Request Path:*  
     `GET https://api.mangadex.org/manga?title={query}&limit=20&offset=0&includes[]=cover_art&includes[]=author&contentRating[]=safe&contentRating[]=suggestive`
   * *Field JSON yang di-mapping:*
     * `data[].id` (UUID String): Identifier unik manga.
     * `data[].attributes.title` (`Map<String, String>`): Judul dalam berbagai bahasa (misal `{"en": "Chainsaw Man", "ja-ro": "Chainsaw Man"}`).
     * `data[].attributes.description` (`Map<String, String>`): Sinopsis terlengkap (tersedia dalam bahasa Inggris maupun Indonesia jika ada).
     * `data[].attributes.status` (String): `"ongoing"`, `"completed"`, `"hiatus"`, `"cancelled"`.
     * `data[].attributes.tags[].attributes.name.en`: Daftar nama genre/tag.
     * `data[].relationships[type="cover_art"].attributes.fileName`: Nama berkas gambar cover.

2. **Katalog & Penjelajahan (Browse: Populer & Rilis Terbaru):**
   * *Populer:*  
     `GET https://api.mangadex.org/manga?order[followedCount]=desc&limit=20&offset=0&includes[]=cover_art&contentRating[]=safe&contentRating[]=suggestive&availableTranslatedLanguage[]=id&availableTranslatedLanguage[]=en`
   * *Chapter Rilis Terbaru:*  
     `GET https://api.mangadex.org/chapter?order[publishAt]=desc&limit=100&offset=0&translatedLanguage[]=id&translatedLanguage[]=en&includeEmptyPages=0`
   * *Filter Berdasarkan Genre (Tag):*  
     `GET https://api.mangadex.org/manga?includedTags[]={tagUuid}&limit=20`

3. **Detail Komik:**
   * *Request Path:*  
     `GET https://api.mangadex.org/manga/{id}?includes[]=cover_art&includes[]=author&includes[]=artist`
   * *Field JSON yang di-mapping:*
     * `data.attributes.originalLanguage`: `"ja"` (manga), `"ko"` (manhwa), `"zh"` (manhua).
     * `data.attributes.year`: Tahun rilis awal.
     * `data.relationships[type="author"].attributes.name`: Nama penulis.
     * `data.relationships[type="artist"].attributes.name`: Nama ilustrator.

4. **Daftar Chapter (Chapter Feed):**
   * *Request Path:*  
     `GET https://api.mangadex.org/manga/{id}/feed?translatedLanguage[]=id&translatedLanguage[]=en&order[chapter]=asc&limit=500&includes[]=scanlation_group`
   * *Field JSON yang di-mapping:*
     * `data[].id` (UUID): ID unik chapter.
     * `data[].attributes.chapter` (String): Nomor chapter (misal `"1"`, `"10.5"`). String wajib dipertahankan untuk mengakomodasi nomor desimal.
     * `data[].attributes.title` (String): Judul chapter (dapat bernilai `null`).
     * `data[].attributes.translatedLanguage` (String): `"id"` (Indonesia) atau `"en"` (Inggris).
     * `data[].attributes.pages` (Int): Jumlah halaman.
     * `data[].attributes.externalUrl` (String?): **Kritis!** Jika bernilai non-null (biasanya chapter rilis resmi MangaPlus/Bilibili/Comikey), chapter ini tidak di-host di MangaDex dan harus dibuka di browser eksternal atau disaring dari reader in-app.
     * `data[].relationships[type="scanlation_group"].attributes.name`: Nama kelompok penerjemah.

5. **Halaman Gambar Chapter (Chapter Pages Reader):**
   * *Langkah 1: Ambil Metadata Delivery Server:*  
     `GET https://api.mangadex.org/at-home/server/{chapterId}`
   * *Respon JSON:*
     ```json
     {
       "result": "ok",
       "baseUrl": "https://uploads.mangadex.org",
       "chapter": {
         "hash": "3303dd03ac8d27452cce3f2a882e94b2",
         "data": ["1-f7a7.png", "2-2a5e.png"],
         "dataSaver": ["1-27e7.jpg", "2-b4e2.jpg"]
       }
     }
     ```
   * *Langkah 2: Konstruksi URL Gambar:*
     * Kualitas Original: `{baseUrl}/data/{chapter.hash}/{filename}`
     * Kualitas Data Saver (Hemat Bandwidth): `{baseUrl}/data-saver/{chapter.hash}/{filename}`
   * *URL Cover Manga:*  
     `https://uploads.mangadex.org/covers/{mangaId}/{fileName}` (Dapat ditambahkan akhiran `.512.jpg` atau `.256.jpg` untuk cover berukuran kecil/grid thumbnail).

#### C. Cakupan Bahasa
* Sangat luas (Multilingual). Terdapat ribuan judul dengan terjemahan Bahasa Indonesia (`id`) aktif dari kelompok scanlation lokal, serta terjemahan Bahasa Inggris (`en`) yang merupakan repositori terbesar di MangaDex.

#### D. Batasan Kecepatan (Rate Limits)
* **Global Rate Limit:** ~5 request per detik per alamat IP.
* **Endpoint Khusus `/at-home/server/{id}`:** Maksimal **40 request per menit per IP**.
* **Respons Pelanggaran:** Mengembalikan status HTTP 429 (*Too Many Requests*). Jika client terus memaksakan request, DDoS protection akan memicu ban IP sementara berupa HTTP 403.
* Header informatif yang disertakan: `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Retry-After`.

#### E. Aturan Image Hosting & CDN
* Menggunakan jaringan volunteer global terdistribusi bernama **MangaDex@Home** (`mangadex.network`) dengan fallback server resmi (`uploads.mangadex.org`).
* **Masa Berlaku Base URL:** Nilai `baseUrl` dari endpoint `@Home` dijamin valid selama minimal **15 menit**. Client Android harus meng-cache nilai ini selama pembacaan chapter dan me-refresh jika terjadi error 403/404.
* **Keamanan Header:** Dilarang keras mengirimkan header `Authorization` ke domain image CDN (`*.mangadex.network` atau `uploads.mangadex.org`), karena request akan ditolak mentah-mentah (403) atau membocorkan data privat ke node volunteer.
* **Hotlinking & User-Agent:** MangaDex melarang hotlinking dari browser web asing melalui pengecekan `Referer`. Namun untuk aplikasi mobile native (OkHttp), pengunduhan gambar berjalan mulus asalkan aplikasi menyertakan header `User-Agent` yang jelas dan tidak menyertakan `Referer` domain web terlarang.

#### F. Ketentuan Layanan (ToS) & Atribusi
* **Wajib Atribusi:** Aplikasi wajib mencantumkan kredit kepada MangaDex.
* **Kredit Scanlator:** Wajib menampilkan nama kelompok scanlation per chapter.
* **Larangan Iklan & Monetisasi (Ad-Free Policy):** Aplikasi pihak ketiga **DILARANG KERAS** memasang iklan komersial (AdMob, Unity Ads, dll.) atau memungut biaya langganan (paid service/paywall) atas akses konten MangaDex.

#### G. Kompatibilitas Langsung dengan Android (Tanpa Backend Sendiri)
* **Sangat Tinggi (100% Kompatibel):** Tidak memerlukan server perantara. Client Retrofit/OkHttp Android dapat langsung berkomunikasi dengan `api.mangadex.org`.
* **Syarat Wajib:** Menyertakan header `User-Agent` yang unik dan deskriptif (contoh: `User-Agent: MyMangaApp/1.0.0 (Android; +https://github.com/myuser/myapp)`). Mendukung penuh TLS 1.2 dan TLS 1.3 dengan Server Name Indication (SNI).

### 2.2 ComicK API (`comick.dev`)

* **Kategori Fungsional:** **METADATA & TRACKER ONLY (Status Halaman Chapter Reader: DEPRECATED / DIHENTIKAN)**
* **Base URL:**
  * Platform Baru (Official): `https://api.comick.dev` / `https://comick.dev`
  * Domain Lama (Legacy Scraper): `https://api.comick.fun` / `https://api.comick.io` (Dialihkan / Terproteksi)
* **Dokumentasi Resmi:** [https://comick.dev/docs](https://comick.dev/docs) | [OpenAPI JSON](https://comick.dev/docs/openapi.json)
* **Status API:** Resmi untuk pelacakan (Library/Catalog Tracker), namun fungsionalitas hosting komik bajakan telah ditinggalkan.

#### A. Konteks Evolusi & Fakta Lapangan
Sebelumnya, pengembang pihak ketiga sering melakukan reverse-engineering terhadap `api.comick.fun` untuk mengambil chapter gambar bajakan dari berbagai sumber. Namun, pada rentang akhir 2024 hingga 2026, ComicK secara resmi melakukan re-branding dan migrasi domain menjadi `comick.dev`, bertransformasi menjadi **platform katalog, pelacak (tracker), dan wiki legal**.
Sebagai konsekuensinya:
1. ComicK menghapus/menutup server pengiriman gambar chapter bajakan publik (`meo3.comick.pictures`).
2. Komunitas pembaca komik open-source terbesar (Mihon/Keiyoushi) secara resmi menolak dan menghapus ekstensi ComicK karena ComicK tidak lagi menyediakan halaman chapter komik yang dapat dibaca.
3. API resmi yang tersedia saat ini (`api.comick.dev`) hanya menyediakan data katalog dan sinkronisasi status bacaan (mirip MyAnimeList).

#### B. Mekanisme Otentikasi
* **Catalog API:** Tidak memerlukan otentikasi (None) untuk pencarian dan detail data publik.
* **Library API:** Menggunakan protokol OAuth 2.0 Authorization Code dengan PKCE (S256) untuk mengaitkan akun pembaca. Tersedia pendaftaran free client.

#### C. Endpoint & Mapping JSON (Catalog & Metadata Saja)
* **Pencarian Komik:**  
  `GET https://api.comick.dev/integrations/v1/titles?q={keyword}&media_type=manga`
* **Detail Komik:**  
  `GET https://api.comick.dev/integrations/v1/titles/{hid}`
  * *Field:* `hid` (String unik opaque identifier), `title` (Judul), `desc` (Sinopsis), `rating` (1-10), `cover_url` (URL Gambar).
* **Chapter Pages:** **TIDAK TERSEDIA.** Endpoint chapter legacy telah dimatikan atau dipagari proteksi Cloudflare Turnstile yang memblokir client Android non-browser.

#### D. Batasan Kecepatan & Stabilitas
* Rate limit: 60 request/menit per app/user, 120 request/menit per alamat IP.
* Stabilitas metadata sangat baik, namun **sama sekali tidak dapat digunakan untuk fitur reading in-app**.

### 2.3 AniList GraphQL API

* **Kategori Fungsional:** **METADATA ONLY (Katalog, Sinopsis, Cover HD, Genre, Skor, Relasi Anime-Manga)**
* **Base URL:** `https://graphql.anilist.co`
* **Dokumentasi Resmi:** [https://anilist.gitbook.io/anilist-apiv2-docs/](https://anilist.gitbook.io/anilist-apiv2-docs/)
* **Status API:** Resmi, Sangat Stabil, dan Sudah Terintegrasi di Aplikasi Eksisting.

#### A. Mekanisme Otentikasi
* **None (100% Gratis & Terbuka):** Tidak memerlukan API key atau pendaftaran akun untuk seluruh query katalog publik.

#### B. Endpoint, Query & Mapping JSON
Seluruh request dikirim melalui method `POST https://graphql.anilist.co` dengan header `Content-Type: application/json`.

1. **Pencarian & Penjelajahan Terkurasi (Search & Browse Populer/Genre):**
   ```graphql
   query SearchAndBrowseManga(
     $search: String,
     $page: Int = 1,
     $perPage: Int = 20,
     $sort: [MediaSort] = [POPULARITY_DESC],
     $genre: String
   ) {
     Page(page: $page, perPage: $perPage) {
       pageInfo {
         currentPage
         hasNextPage
         total
       }
       media(search: $search, type: MANGA, sort: $sort, genre: $genre) {
         id
         title {
           romaji
           english
           native
         }
         coverImage {
           extraLarge
           large
           medium
           color
         }
         bannerImage
         description(asHtml: false)
         status
         genres
         averageScore
         popularity
         chapters
         volumes
         startDate {
           year
           month
           day
         }
       }
     }
   }
   ```
   * *Opsi Sort:* `[POPULARITY_DESC]`, `[TRENDING_DESC]`, `[UPDATED_AT_DESC]`, `[FAVOURITES_DESC]`.
   * *Field Mapping:*
     * `media[].id`: AniList ID (dapat dipadankan dengan AniSkip atau metadata anime yang sudah ada).
     * `media[].title`: Judul dalam berbagai alfabet (krusial untuk pencocokan ke sumber reader).
     * `media[].coverImage.extraLarge`: Gambar cover definisi tinggi (HD).
     * `media[].description`: Sinopsis bersih tanpa tag HTML.
     * `media[].averageScore`: Rating komunitas skala 0-100.
     * `media[].chapters`: Total chapter rilis (jika sudah tamat).

2. **Chapter Pages (Halaman Gambar):**
   * **TIDAK ADA.** AniList murni penyedia data bibliografi.

#### C. Batasan Kecepatan (Rate Limits)
* **Ketat:** Maksimal **90 request per menit per IP**.
* Pelanggaran menghasilkan status HTTP 429.
* Response header menyertakan informasi kuota: `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`.

#### D. Image Hosting & Aturan CDN
* Gambar di-host di CDN terkelola AniList/Cloudinary (`s4.anilist.co`).
* Bebas di-hotlink langsung dari aplikasi Android (menggunakan Coil / Glide) tanpa memerlukan `Referer` khusus.

#### E. Kompatibilitas Langsung dengan Android
* **Sempurna.** Mengingat arsitektur saat ini sudah mengonsumsi AniList GraphQL untuk anime, model pemanggilan jaringan yang sama dapat langsung digunakan kembali untuk tipe data `MANGA` tanpa perlu library baru.

### 2.4 Jikan API (Unofficial MyAnimeList v4)

* **Kategori Fungsional:** **METADATA ONLY**
* **Base URL:** `https://api.jikan.moe/v4`
* **Dokumentasi Resmi:** [https://docs.api.jikan.moe/](https://docs.api.jikan.moe/)
* **Status API:** Open-Source Unofficial REST Wrapper untuk MyAnimeList.

#### A. Mekanisme Otentikasi
* **None (100% Gratis):** Tidak memerlukan API key.

#### B. Endpoint, Contoh Request Path & Mapping JSON

1. **Pencarian Manga (Search):**
   * *Path:* `GET https://api.jikan.moe/v4/manga?q={query}&page=1&limit=25&order_by=popularity&sort=desc`
   * *Field Mapping:*
     * `data[].mal_id`: ID unik MyAnimeList (Integer).
     * `data[].title`: Judul utama manga.
     * `data[].images.jpg.large_image_url`: Gambar cover poster resolusi besar.
     * `data[].synopsis`: Teks deskripsi/sinopsis.
     * `data[].status`: `"Publishing"`, `"Finished"`, `"On Hiatus"`.
     * `data[].score`: Rata-rata skor rating MyAnimeList (Float, misal 8.95).
     * `data[].genres[].name`: Array nama genre.
     * `data[].authors[].name`: Nama pengarang.

2. **Katalog Manga Terbaik (Top Manga / Popular):**
   * *Path:* `GET https://api.jikan.moe/v4/top/manga?type=manga&filter=bypopularity&page=1`

3. **Detail Komprehensif:**
   * *Path:* `GET https://api.jikan.moe/v4/manga/{id}/full`
   * Mengembalikan relasi karya (adaptasi anime, spin-off), rekomendasi judul terkait, dan karakter.

4. **Chapter Pages (Halaman Gambar):**
   * **TIDAK ADA.**

#### C. Batasan Kecepatan & Stabilitas
* **Batas Request:**
  * **3 request per detik.**
  * **60 request per menit.**
* Mengembalikan HTTP 429 jika melebihi batas. Server Jikan menerapkan caching berlapis, namun jika traffic global dari banyak pengguna melonjak, respon kadang lambat.

#### D. Kompatibilitas Langsung dengan Android
* Bekerja langsung dari Android melalui Retrofit. Namun, batasan 3 req/detik menuntut penanganan ketat pada client: wajib menyematkan rate-limiter interceptor pada OkHttp dan mendebounce input form pencarian agar tidak langsung memicu 429.

### 2.5 Kitsu API

* **Kategori Fungsional:** **METADATA ONLY**
* **Base URL:** `https://kitsu.io/api/edge`
* **Dokumentasi Resmi:** [https://kitsu.docs.apiary.io/](https://kitsu.docs.apiary.io/)
* **Status API:** Resmi (Official Kitsu Edge API).

#### A. Mekanisme Otentikasi
* **None (100% Gratis untuk Baca Data Publik):** Tidak membutuhkan token untuk pencarian dan detail katalog.

#### B. Endpoint & Mapping JSON (Format Standar JSON:API)

1. **Pencarian Manga:**
   * *Path:* `GET https://kitsu.io/api/edge/manga?filter[text]={query}&page[limit]=20&page[offset]=0`
2. **Browse Berdasarkan Popularitas:**
   * *Path:* `GET https://kitsu.io/api/edge/manga?sort=-userCount&page[limit]=20`
3. **Detail Komik & Kategori:**
   * *Path:* `GET https://kitsu.io/api/edge/manga/{id}?include=genres,categories`
   * *Field Mapping (Struktur JSON:API):*
     * `data[].id`: ID Kitsu.
     * `data[].attributes.canonicalTitle`: Judul resmi.
     * `data[].attributes.synopsis`: Sinopsis.
     * `data[].attributes.posterImage.original`: URL cover poster.
     * `data[].attributes.averageRating`: Skor persentase (misal `"83.45"`).
     * `data[].attributes.chapterCount`: Estimasi total chapter.
4. **Chapter Pages:** **TIDAK ADA.**

#### C. Batasan Kecepatan & Kompatibilitas Android
* Rate limit: Sekitar 60 request per menit.
* Kompatibilitas: Bekerja langsung via OkHttp. Tantangan utama terletak pada parsing Moshi/Kotlin Serialization karena Kitsu mengadopsi spesifikasi formal JSON:API (di mana atribut bersarang di dalam blok `data.attributes` dan relasi disimpan di array terpisah `included`).

### 2.6 MangaUpdates (Baka-Updates Manga) API

* **Kategori Fungsional:** **METADATA & SCANLATION RELEASE TRACKER ONLY**
* **Base URL:** `https://api.mangaupdates.com/v1`
* **Dokumentasi Resmi:** [https://api.mangaupdates.com/](https://api.mangaupdates.com/)
* **Spesifikasi OpenAPI:** [https://api.mangaupdates.com/openapi.yaml](https://api.mangaupdates.com/openapi.yaml)
* **Status API:** Resmi (Official v1 REST API).

#### A. Mekanisme Otentikasi
* **None (100% Gratis untuk Read-Only):** Pengambilan data serial, rilis, grup scanlator, dan pencarian tidak membutuhkan akun.

#### B. Endpoint, Contoh Request Path & Mapping JSON

1. **Pencarian Komik (Search Series):**
   * *Request:* `POST https://api.mangaupdates.com/v1/series/search`
   * *Body JSON:* `{"search": "Solo Leveling", "stype": "title", "page": 1, "perpage": 20}`
   * *Field Mapping:*
     * `results[].record.series_id`: ID seri unik (Long).
     * `results[].record.title`: Judul komik.
     * `results[].record.description`: Sinopsis.
     * `results[].record.image.url.original`: Gambar sampul.
     * `results[].record.genres[].genre`: Genre.
     * `results[].record.year`: Tahun terbit.
     * `results[].record.bayesian_rating`: Nilai rating komunitas berbobot.

2. **Detail Komik & Info Lisensi:**
   * *Path:* `GET https://api.mangaupdates.com/v1/series/{id}`
   * *Field Tambahan:*
     * `associated`: Daftar judul alternatif (termasuk judul transliterasi Korea/Cina/Jepang).
     * `licensed`: Status apakah judul telah dilisensikan oleh penerbit resmi di wilayah berbahasa Inggris.
     * `english_publisher`: Nama penerbit legal (jika ada).

3. **Indeks Rilis Terbaru (Release Tracking):**
   * *Path:* `GET https://api.mangaupdates.com/v1/releases/days`
   * Mengembalikan daftar rilis terjemahan komik harian dari berbagai grup scanlation di seluruh dunia.

4. **Chapter Pages (Halaman Gambar):**
   * **TIDAK ADA.** MangaUpdates adalah direktori indeks bibliografi dan riwayat rilis scanlation, bukan platform hosting pembaca gambar.

#### C. Batasan Kecepatan & Stabilitas
* Rate limit: Rekomendasi sopan 1-2 request per detik. Terlindungi oleh Cloudflare dasar, sehingga header `User-Agent` standar wajib disertakan.
* Stabilitas: Sangat tinggi. Database berjalan puluhan tahun dengan struktur data yang konsisten.

### 2.7 Consumet API (Public Instances & Self-Hosted)

* **Kategori Fungsional:** **AGGREGATOR SCRAPER MULTI-PROVIDER (Menyediakan Chapter Pages & Metadata)**
* **Base URL:**
  * Instance Publik: `https://api.consumet.org` (Sangat tidak stabil / sering down)
  * Self-Hosted (Free Tier Render / Koyeb / Docker): `https://my-consumet-app.onrender.com`
* **Dokumentasi Resmi:** [https://docs.consumet.org/](https://docs.consumet.org/)
* **Repositori GitHub:** [https://github.com/consumet/api.consumet.org](https://github.com/consumet/api.consumet.org)
* **Status API:** Open-Source Web Scraping Wrapper Library (Reverse-Engineered).

#### A. Mekanisme Otentikasi
* **None (100% Gratis):** Baik instance publik maupun self-host di platform gratisan (seperti Render Free Plan atau Vercel) tidak memerlukan biaya maupun API key.

#### B. Provider yang Didukung
* `mangadex`, `mangakakalot`, `mangapark`, `mangapill`, `mangareader`, `asurascans`, `flamescans`.

#### C. Endpoint, Contoh Request Path & Mapping JSON

1. **Pencarian Manga:**
   * *Path:* `GET https://api.consumet.org/manga/{provider}/{query}?page=1`
   * Contoh Provider `mangakakalot`: `GET /manga/mangakakalot/naruto?page=1`
   * *Field Mapping:*
     * `results[].id`: Identifier spesifik provider (misal `"naruto"` atau `"manga-ox923482"`).
     * `results[].title`: Judul manga.
     * `results[].image`: URL gambar cover.

2. **Detail Komik & Daftar Chapter:**
   * *Path:* `GET https://api.consumet.org/manga/{provider}/info?id={mangaId}`
   * *Field Mapping:*
     * `id`, `title`, `description`, `genres[]`, `status`.
     * `chapters[].id`: Identifier unik chapter yang akan dipakai untuk membaca.
     * `chapters[].title`: Judul atau nomor chapter.
     * `chapters[].releasedDate`: Tanggal rilis.

3. **Halaman Gambar Chapter (Chapter Pages):**
   * *Path:* `GET https://api.consumet.org/manga/{provider}/read?chapterId={chapterId}`
   * *Respon JSON:*
     ```json
     [
       { "page": 1, "img": "https://images.example.com/ch1/p1.jpg" },
       { "page": 2, "img": "https://images.example.com/ch1/p2.jpg" }
     ]
     ```
   * *Field Mapping:*
     * `img`: URL absolut berkas gambar halaman.
     * `page`: Nomor urut halaman (Integer).

4. **Meta Endpoint (Jembatan AniList + Provider Manga):**
   * *Path:* `GET https://api.consumet.org/meta/anilist-manga/read?chapterId={chapterId}&provider=mangadex`
   * Memungkinkan pencarian menggunakan metadata AniList dan secara otomatis meresolusi chapter pages dari provider yang dipilih.

#### D. Image Hosting & Aturan Hotlink
* URL gambar yang dihasilkan merujuk langsung ke server CDN asal dari provider target (misal CDN Blogspot, Cloudflare, atau server Mangakakalot).
* Sebagian besar provider (seperti Mangakakalot) menerapkan hotlink protection ketat (HTTP 403 Forbidden jika `Referer` tidak sesuai). Client Android OkHttp wajib menyuntikkan header `Referer: https://mangakakalot.com/` pada image loader (Coil).
* Consumet menyediakan rute `/utils/image-proxy?url={imageUrl}&headers={jsonHeaders}` untuk membantu melakukan bypass.

#### E. Stabilitas & Kelayakan Langsung dari Android (Tanpa Backend Sendiri)
* **Instance Publik (`api.consumet.org`): SANGAT BURUK.** Mengalami seringnya downtime, pembatasan rate limit ekstrem oleh Vercel/Cloudflare, dan kegagalan scraping saat situs target memperbarui DOM HTML.
* **Self-Hosted (Render / Koyeb / Docker): CUKUP BAIK.** Dapat di-deploy gratis dalam hitungan menit, namun tetap menuntut pemeliharaan kode saat library scraping perlu di-update mengikuti perubahan situs asal.
* **Kesimpulan Android Direct:** Tidak direkomendasikan mengandalkan instance publik orang lain di dalam kode produksi Android tanpa proxy server sendiri.

#### A. Mekanisme Otentikasi
* **None (100% Gratis):** Sepenuhnya terbuka tanpa API key.

#### B. Endpoint, Contoh Request Path & Mapping JSON (Studi Kasus: Komiku REST API)

1. **Pencarian Komik:**
   * *Path:* `GET https://komiku-rest-api.vercel.app/search?q={keyword}`
2. **Katalog & Penjelajahan:**
   * *Komik Terbaru:* `GET https://komiku-rest-api.vercel.app/terbaru`
   * *Populer Manga/Manhwa:* `GET https://komiku-rest-api.vercel.app/komik-populer/manhwa`
   * *Pustaka Terpaginasi:* `GET https://komiku-rest-api.vercel.app/pustaka/page/{page}`
   * *Filter Genre:* `GET https://komiku-rest-api.vercel.app/genre/{slug}/page/{page}`
3. **Detail Komik:**
   * *Path:* `GET https://komiku-rest-api.vercel.app/detail-komik/{slug}`
   * *Field Mapping:*
     * `title`: Judul Bahasa Indonesia.
     * `sinopsis`: Teks ringkasan cerita Bahasa Indonesia.
     * `thumbnail`: URL cover dari CDN Komiku.
     * `info["Jenis Komik"]`: `"Manga"`, `"Manhwa"`, `"Manhua"`.
     * `info["Status"]`: `"Berjalan"`, `"Tamat"`.
     * `genres[]`: Array genre.
     * `chapters[].title`: Label judul chapter (misal `"Chapter 220"`).
     * `chapters[].chapterNumber`: Nomor chapter (misal `"220"`).
     * `chapters[].apiLink`: Path relatif membaca (`"/baca-chapter/reality-quest/220"`).
4. **Halaman Gambar Chapter (Chapter Pages):**
   * *Path:* `GET https://komiku-rest-api.vercel.app/baca-chapter/{slug}/{chapterNumber}`
   * *Field Mapping:*
     * `images[].src`: URL berkas gambar halaman (misal `https://img.komiku.to/upload/...`).
     * `images[].id`: Urutan nomor halaman.
     * `navigation.prevChapter.chapter`: Nomor chapter sebelumnya.
     * `navigation.nextChapter.chapter`: Nomor chapter berikutnya.
5. **Image Proxy Terintegrasi:**
   * *Path:* `GET https://komiku-rest-api.vercel.app/image-proxy?url={imageUrl}`

#### C. Masalah Kritis Image Hosting & Proteksi CDN Komik Indonesia
* Server penyimpanan gambar situs komik lokal (`img.komiku.to`, `thumbnail.komiku.to`, server Kiryuu) menerapkan **hotlink anti-leeching**.
* Jika aplikasi Android memuat gambar tanpa konfigurasi header yang tepat, server akan mengembalikan respon **HTTP 403 Forbidden**.
* **Solusi Client Android (OkHttp/Coil):** Interceptor wajib menyematkan header:
  * `Referer: https://komiku.org/` (atau domain aktif komik terkait).
  * `User-Agent: Mozilla/5.0 (Linux; Android 14; Mobile)...`

#### D. Evaluasi Stabilitas & Kendala Operasional Nyata
1. **Batas Bandwidth Serverless (Vercel HTTP 402 Payment Required):**  
   Pengujian live terhadap instance publik `komiku-rest-api.vercel.app` memperlihatkan error langsung: **HTTP 402 (Payment Required)**. Hal ini terjadi karena akun gratis Vercel pengembang pembuat scraper telah melampaui kuota eksekusi serverless dan bandwidth bulanan.
2. **Siklus Hidup Domain yang Sangat Cepat (Domain Churn):**  
   Situs-situs komik bajakan Indonesia terus-menerus diblokir oleh Kominfo / Internet Positif atau terkena komplain DMCA. Berdasarkan riwayat issue di Keiyoushi:
   * *Komikcast:* Berganti domain beruntun dari `komikcast.lol` → `komikcast.moe` → `komikcast.mom` → `komikcast05` → `VoraToon`.
   * *Komiku:* Berganti domain dari `komiku.id` → `komiku.to` → `komiku.org`.
3. **Perubahan Struktur HTML (DOM Breakdown):**  
   Setiap kali situs target memperbarui layout web, parser Cheerio/Jsoup pada scraper akan menghasilkan array kosong (`empty list`) hingga pembuatnya merilis patch kode.

## 4. Rekomendasi Arsitektur & Strategi Implementasi Android

Untuk menghasilkan aplikasi Android yang kokoh, cepat, berbiaya Rp 0, dan tidak sering rusak, direkomendasikan pola arsitektur **Hybrid Decoupled Architecture**:

```
+-----------------------------------------------------------------------------------+
|                        JETPACK COMPOSE UI LAYER (KOTLIN)                          |
+-----------------------------------------------------------------------------------+
       | (Discover, Browse, Cover HD, Genre)          | (Search, Chapters, Page Images)
       v                                              v
+-------------------------------+              +------------------------------------+
|    METADATA SERVICE           |              |       READER & CHAPTER SERVICE     |
|  AniList GraphQL (Eksisting)  |              |          MangaDex API v5           |
+-------------------------------+              +------------------------------------+
       |                                              |
       | Metadata Caching                             | Image & Chapter Caching
       v                                              v
+-----------------------------------------------------------------------------------+
|                     ROOM DATABASE & OKHTTP CLIENT (CACHE & OFFLINE)               |
+-----------------------------------------------------------------------------------+
                                                      | (Jika Chapter Tidak Ditemukan)
                                                      v
                                               +------------------------------------+
                                               |          FALLBACK ENGINE           |
                                               | In-App HTML Parser / Self-Host API |
                                               |  (Komiku / Mangakakalot Scraper)   |
                                               +------------------------------------+
```

### 4.1 Sumber Utama Pembacaan Komik (Best Primary Source for Full Reading): **MangaDex API v5**
* **Mengapa MangaDex?**
  1. **Legalitas & Kestabilan:** Memiliki infrastruktur resmi berizin dan API terbuka (OpenAPI), bukan sekadar scraper yang sewaktu-waktu pecah saat website berganti tema.
  2. **Dukungan Bahasa Indonesia & Inggris:** MangaDex adalah rumah bagi ratusan grup scanlation Indonesia dan internasional. Judul-judul populer maupun indie memiliki opsi bahasa `id` dan `en`.
  3. **Infrastruktur Gambar MangaDex@Home:** Mengalokasikan server pengiriman gambar terdistribusi yang cepat dan andal, serta menyediakan varian `dataSaver` untuk menghemat kuota internet pengguna Android.
  4. **Direct OkHttp Support:** Dapat langsung dipanggil dari Android tanpa backend perantara, asalkan aplikasi menyertakan `User-Agent` yang unik.
* **Aturan Implementasi OkHttp & Coil:**
  * Cache `baseUrl` dari `/at-home/server/{chapterId}` selama 15 menit menggunakan Room atau Memory Cache.
  * Saring chapter dengan atribut `externalUrl != null` agar aplikasi tidak mencoba membuka chapter yang dialihkan ke situs luar (seperti MangaPlus).
  * Hormati kebijakan MangaDex: **Aplikasi tidak boleh menampilkan iklan (ad-free) dan wajib mencantumkan atribusi MangaDex serta nama Scanlation Group**.

### 4.2 Sumber Metadata Terbaik (Best Free Metadata Source to Pair): **AniList GraphQL**
* **Mengapa AniList?**
  1. **Efisiensi Kode (Code Reusability):** Aplikasi sudah menggunakan AniList GraphQL untuk anime. Model `Media` GraphQL AniList secara native mendukung `type: MANGA` dengan struktur query yang identik.
  2. **Kualitas Data Visual:** Cover ekstra besar (HD), banner beresolusi tinggi, ranking trending, dan relasi langsung antara anime dengan manga aslinya.
  3. **Pola Integrasi (Mapping Judul):**
     * Tampilkan halaman Discover/Browse (Trending Manga, Popular, Top Rated) menggunakan AniList GraphQL.
     * Ketika pengguna membuka detail manga dan menekan "Mulai Membaca", gunakan judul Romaji atau judul Inggris dari AniList untuk melakukan pencarian query otomatis ke MangaDex API (`GET /manga?title={title}`).
     * Tautkan ID MangaDex yang cocok ke entitas Room database lokal agar pemanggilan berikutnya instan.

### 4.3 Sumber Cadangan (Fallback Source)
* **Kebutuhan:** Terkadang judul komik tertentu (misal manga terbitan Shueisha/Viz) dihapus dari MangaDex karena permintaan DMCA resmi, atau terjemahan Bahasa Indonesia tertentu hanya rilis di situs scraper lokal (seperti Komiku / Komikcast).
* **Strategi Cadangan:**
  1. **Opsi 1 (Direkomendasikan Tanpa Server): Client-Side In-App Parser (Tachiyomi-style).**  
     Alih-alih bergantung pada scraper REST API milik orang lain di Vercel yang rawan terkena HTTP 402, sematkan parser HTML ringan berbasis **Jsoup** langsung di dalam kode Kotlin aplikasi untuk membaca situs seperti `komiku.org`.
  2. **Opsi 2: Self-Hosted Consumet API.**  
     Deploy repositori `consumet/api.consumet.org` secara mandiri ke platform gratis seperti **Render Free Web Service** atau **Koyeb**. Karena dikelola sendiri, Anda tidak akan terkena limitasi traffic pengguna publik lain.

## 5. Analisis Risiko Utama & Langkah Mitigasi

### 5.1 Risiko 1: Pembatasan Kecepatan (Rate Limiting & HTTP 429)
* **Penyebab:** MangaDex membatasi 40 req/menit pada endpoint `@Home`, sedangkan AniList membatasi 90 req/menit. Scroll cepat pengguna di Compose UI dapat membanjiri antrean jaringan.
* **Mitigasi Teknis di Android:**
  * Pasang **OkHttp Interceptor** dengan RateLimiter berbasis Coroutine Semaphore atau Token Bucket (maksimal 3 request per detik).
  * Terapkan **Exponential Backoff Retry Interceptor** khusus untuk kode status HTTP 429, dengan membaca nilai header `X-RateLimit-Retry-After` atau `Retry-After`.
  * Simpan seluruh respon katalog dan detail komik ke dalam database lokal **Room** (Single Source of Truth pattern). Jika data sudah ada di Room dan belum berusia 24 jam, sajikan langsung dari disk tanpa request jaringan.

### 5.2 Risiko 2: Masalah DMCA Takedown & External Chapter Links
* **Penyebab:** Penerbit resmi (seperti Shueisha melalui MANGA Plus, Kodansha, atau Webtoon) secara aktif mengirimkan notice DMCA. Pada MangaDex, chapter resmi hanya menyertakan link eksternal (`externalUrl`) dan tidak menyediakan gambar di server MangaDex.
* **Mitigasi Teknis di Android:**
  * Di DTO Moshi, periksa: `val isExternal: Boolean = !externalUrl.isNullOrEmpty()`.
  * Jika bernilai `true`, berikan indikator visual ikon link eksternal pada UI chapter list di Jetpack Compose. Ketika ditekan, luncurkan **Android Custom Tabs** menuju URL tersebut, alih-alih melempar error pada in-app reader.

### 5.3 Risiko 3: Domain Churn & Blokir Internet Positif (Khusus Komik Indonesia)
* **Penyebab:** Situs komik Indonesia sering diblokir ISP lokal (Kominfo) atau berganti nama domain untuk menghindari takedown.
* **Mitigasi Teknis di Android:**
  * Jangan pernah melakukan *hardcode* domain situs komik lokal ke dalam kode biner APK.
  * Gunakan mekanisme **Remote Dynamic Configuration** sederhana (misalnya file `config.json` di GitHub Gist atau Firebase Remote Config gratis) yang memuat alamat domain aktif (contoh: `komiku_base_url: "https://komiku.org"`). Jika domain berganti, Anda cukup mengedit Gist tanpa harus merilis ulang APK ke pengguna.

### 5.4 Risiko 4: Kebijakan Google Play Store & Aspek Hukum
* **Penyebab:** Aplikasi yang menyediakan akses baca komik bajakan tanpa hak cipta melanggar *Intellectual Property Policy* Google Play Store. Aplikasi berisiko tinggi di-suspend atau akun developer dibanned secara permanen jika didistribusikan secara terbuka di Play Store dengan reader komik bajakan aktif.
* **Mitigasi Distribusi:**
  * Model Tachiyomi/Mihon/Aniyomi: Distribusikan aplikasi melalui **GitHub Releases** atau **F-Droid**.
  * Jika tetap ingin merilis di Google Play Store: Desain aplikasi murni sebagai *Media Tracker* (hanya menampilkan metadata AniList dan tracking bacaan), sementara modul ekstensi pembaca komik diunduh secara modular terpisah oleh pengguna.

## 6. Contoh Desain Kode Kotlin (Retrofit, Moshi & OkHttp)

Berikut adalah cetak biru implementasi client jaringan untuk integrasi MangaDex API v5 di Android:

```kotlin
// 1. Interceptor User-Agent Wajib untuk MangaDex
class MangaDexHeaderInterceptor : Interceptor {
    override fun intercept(chain: Interceptor.Chain): Response {
        val originalRequest = chain.request()
        val requestWithHeaders = originalRequest.newBuilder()
            .header("User-Agent", "AnimeInMangaClient/1.0 (Android; +https://github.com/example/app)")
            .build()
        return chain.proceed(requestWithHeaders)
    }
}

// 2. Moshi Data Transfer Objects (DTO) untuk At-Home Delivery
@JsonClass(generateAdapter = true)
data class AtHomeServerResponse(
    @Json(name = "baseUrl") val baseUrl: String,
    @Json(name = "chapter") val chapter: AtHomeChapterData
)

@JsonClass(generateAdapter = true)
data class AtHomeChapterData(
    @Json(name = "hash") val hash: String,
    @Json(name = "data") val dataOriginal: List<String>,
    @Json(name = "dataSaver") val dataSaver: List<String>
)

// 3. Retrofit Interface untuk MangaDex
interface MangaDexApiService {
    @GET("manga")
    suspend fun searchManga(
        @Query("title") title: String,
        @Query("limit") limit: Int = 20,
        @Query("offset") offset: Int = 0,
        @Query("includes[]") includes: List<String> = listOf("cover_art", "author"),
        @Query("contentRating[]") ratings: List<String> = listOf("safe", "suggestive")
    ): MangaListResponse

    @GET("manga/{id}/feed")
    suspend fun getChapterFeed(
        @Path("id") mangaId: String,
        @Query("translatedLanguage[]") languages: List<String> = listOf("id", "en"),
        @Query("order[chapter]") order: String = "asc",
        @Query("limit") limit: Int = 500
    ): ChapterFeedResponse

    @GET("at-home/server/{chapterId}")
    suspend fun getChapterPages(
        @Path("chapterId") chapterId: String
    ): AtHomeServerResponse
}

// 4. Helper Konstruksi URL Gambar Pembaca
object MangaDexImageResolver {
    fun buildPageUrl(
        baseUrl: String,
        chapterHash: String,
        fileName: String,
        useDataSaver: Boolean = true
    ): String {
        val qualityPath = if (useDataSaver) "data-saver" else "data"
        return "$baseUrl/$qualityPath/$chapterHash/$fileName"
    }

    fun buildCoverUrl(mangaId: String, fileName: String, thumbSize: String = ".512.jpg"): String {
        return "https://uploads.mangadex.org/covers/$mangaId/$fileName$thumbSize"
    }
}
```
